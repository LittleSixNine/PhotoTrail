```powershell
dotnet build PhotoTrail.Windows/PhotoTrail.Windows.csproj
```

工作目录为本文件所在的 `apps/windows`。ExifTool 必须使用完整 Windows 原生发行目录，保留随附文件；也可放入应用输出目录的 `tools/exiftool/`。开发时还可使用未纳入版本控制的 `bin/.../development-tool.json`，内容为 `{"executable":"ExifTool的绝对路径"}`。不在公开源码写入本机路径或凭据。

导入支持多选、拖入和当前层文件夹。XMP 从同名旁车优先读取，其他原始字段按来源分开显示。JPEG、XMP 可编辑27项常用XMP：作者、标题、说明、关键词、拍摄时间、国家、省/州、城市、地点、国家代码、版权、评分、标签、制造商、设备型号、镜头、镜头序列号、数字化时间、创建时间、修改时间、曝光时间、光圈、ISO、焦距、曝光补偿、曝光程序、白平衡；RAW 等图像已有同名旁车时只编辑旁车。其他格式仅读取。标题和说明只改 x-default，作者和关键词每行一项。拍摄时间格式为 `yyyy:MM:dd HH:mm:ss`，可附 `+09:00` 等时区，支持1至9位小数秒原样保留。

选择照片，勾选要改的字段并输入，点击“应用”；勾选且留空代表清除。多选的混合值不自动清除。“清空所选全部草稿”清空所选全部待保存修改；“撤销最近一次应用”仅恢复最近一批之前的完整草稿。指定已有输出文件夹，点击“保存所选草稿为副本”；同名文件拒绝覆盖，源文件始终保留，成功副本仍保留源草稿。保存逐张执行，失败不阻止其余项目；取消保留已完成的副本。退出有草稿时提示，任务进行时先取消并等待结束。

默认地图使用本地 MapLibre 6.13.0 与 OpenFreeMap 在线底图。需要网络，不需要密钥；地图支持WGS84选点／拖动预览标记／轨迹匹配预览，显式加入GPS草稿后可另存副本；不自动写入、不查询地址。Google地图渲染和地区查询预览、可恢复重命名已实现；Google真实API、完整字段与正式安装包仍待验或开发。
