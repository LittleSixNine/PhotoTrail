# PhotoTrail Windows 开发原型

[行为约定](docs/BEHAVIOR.md) · [开发记录](docs/CHANGELOG.md) · [构建入口](docs/DEVELOPMENT.md)

Windows源码及公共文档的提交范围为本目录，Mac共享路径保持不变。当前阶段2本机验收通过，阶段3已接入GPX/KML/KMZ轨迹预览、时间匹配、GPS草稿与安全副本保存；完整Windows功能及不同DPI仍未完成。私人Windows日志与验证记录在私有工作区的独立windows目录保存，不进入本公开仓库。

当前为本地验证工程，尚未交付 Windows 安装包。需要 Windows 11 x64、.NET SDK 10.0.401 或兼容的 .NET 10 SDK，以及 WebView2 Runtime。

```powershell
dotnet build PhotoTrail.Windows/PhotoTrail.Windows.csproj
$env:PHOTOTRAIL_EXIFTOOL = '工具所在目录/ExifTool.exe'
dotnet run --project PhotoTrail.Windows/PhotoTrail.Windows.csproj -- '照片所在目录/sample.jpg'
```

工作目录为本文件所在的 `apps/windows`。ExifTool 必须使用完整 Windows 原生发行目录，保留随附文件；也可放入应用输出目录的 `tools/exiftool/`。开发时还可使用未纳入版本控制的 `bin/.../development-tool.json`，内容为 `{"executable":"ExifTool的绝对路径"}`。不在公开源码写入本机路径或凭据。

导入支持多选、拖入和当前层文件夹。XMP 从同名旁车优先读取，其他原始字段按来源分开显示。JPEG、XMP 可编辑27项常用XMP：作者、标题、说明、关键词、拍摄时间、国家、省/州、城市、地点、国家代码、版权、评分、标签、制造商、设备型号、镜头、镜头序列号、数字化时间、创建时间、修改时间、曝光时间、光圈、ISO、焦距、曝光补偿、曝光程序、白平衡；RAW 等图像已有同名旁车时只编辑旁车。其他格式仅读取。标题和说明只改 x-default，作者和关键词每行一项。拍摄时间格式为 `yyyy:MM:dd HH:mm:ss`，可附 `+09:00` 等时区，支持1至9位小数秒原样保留。

选择照片，勾选要改的字段并输入，点击“加入草稿”；勾选且留空代表清除。多选的混合值不自动清除。“撤销所选草稿”恢复源文件读数。指定已有输出文件夹，点击“保存所选草稿为副本”；同名文件拒绝覆盖，源文件始终保留，成功副本仍保留源草稿。保存逐张执行，失败不阻止其余项目；取消保留已完成的副本。退出有草稿时提示，任务进行时先取消并等待结束。

默认地图使用本地 MapLibre 6.13.0 与 OpenFreeMap 在线底图。需要网络，不需要密钥；地图支持WGS84选点／拖动预览标记／轨迹匹配预览，显式加入GPS草稿后可另存副本；不自动写入、不查询地址。Google地图渲染和地区查询预览、可恢复重命名已实现；Google真实API、完整字段与正式安装包仍待验或开发。

地图页提供“重载地图”：底图加载失败后可重新加载页面，保留照片、当前轨迹、GPS/字段草稿及位置预览；新页面就绪后重放图层。任务及地图初始化期间禁用重载。在线重载和样式加载失败后的恢复已实机验证；持续离线、浏览器进程退出与初始化超时恢复仍待验。

地图加载失败时原生状态栏同步提示重载。无需ExifTool可运行 `dotnet run --project PhotoTrail.Windows.Tests/PhotoTrail.Windows.Tests.csproj -- --map-checks`（25项地图消息检查）；网页检查现为12项。

地图设置页已提供Google密钥本机保存/删除，使用Windows当前用户DPAPI保护，不回显已存内容，保存后清空输入；保存不联网验证。默认仍为OpenFreeMap，可明确切换Google地图并查询地区预览；真实API仍待用户自行配置验收。密钥格式限制20至256位英文字母/数字/横线/下划线。更换电脑或Windows用户后重新输入；同用户进程仍可能解密，不能替代Google限制/配额。

Google入口使用受限本地页面，只有明确点击使用Google才解密并注入网页SDK；默认每次启动OpenFreeMap。查询当前位置由单独按钮触发，20秒超时、请求版本与坐标防止旧结果回写。结果标识Google Maps，仅当前预览，不自动写照片或日志。Google结果持久写入的许可适用性仍待核实，参见 https://developers.google.com/maps/documentation/geocoding/policies 。

手填国家、省/州、城市、区/地点与三字母国家码写XMP-photoshop Country/State/City和XMP-iptcCore Location/CountryCode，最多256字且无控制字符。原IPTC/EXIF保留；勾选留空才清除，未勾选字段不改。

重命名页沿用所选照片，规则逐行从上到下作用于主名，保留扩展名，支持前缀/后缀/替换/设名/大小写/序号。可按名称排序；即时名称预览不改文件，检查冲突/内容哈希后冻结，改规则或选择使计划失效。有草稿/未应用输入/导入后外部变动/新旁车时不执行。

执行先全部暂存再落最终名，不覆盖其他文件。已核验Windows句柄禁止外部写/移，逐步记录且更名后再核验SHA256。执行中取消/失败保留每项实际名称和执行记录；按记录恢复核验内容，恢复也生成记录，可按该记录撤销恢复。部分更名恢复前暂停元数据编辑，避免旁车暂存关系误写。最近记录在重启后回读；损坏/变化的记录或文件不强行恢复。

## 批量读取与启动路径

当前以32个主文件为批次复用ExifTool多文件读取，主图/旁车版本核验与逐文件失败记录保留。CLI可传文件或文件夹，文件夹只展开当前层；已有界面导入与拖入相同。300张核心22.11秒、3000张220.20秒为本机单次样本，主进程3000峰值约295MiB，不含GUI/工具子进程；完整界面压力验收继续进行。

文件名搜索不区分大小写；可筛选有/无草稿、有/无可用定位并按名称升降序。隐藏照片与草稿保留，列表显示可见数/总数/全部草稿数。任务中禁用视图变更，未应用输入须先处理。导入完成显示总用时。

重命名页可保存/载入Windows JSON规则（包含有序文字规则与排序选项）。载入只更新预览并使冻结计划失效，须重新检查冲突；文件不覆盖。当前格式与Mac规则预设不同。

地图页显示最近20条本机轨迹路径。仅成功读取后记录，重启不自动加载；明确点击重新读取才解析当前文件。同一Windows会话的多个实例合并最新历史，不丢失另一实例刚加入的路径。历史记录失败不影响会话导入。

快捷键：Ctrl+O导入照片，Ctrl+Shift+O导入当前层文件夹，Ctrl+S保存所选草稿副本，F3文件名搜索，Esc取消正在进行的任务。未应用输入须先加入草稿；文本框原生复制/粘贴/撤销不被拦截。

XMP交换页可导出一个文件的完整现有XMP包及草稿，不覆盖目标，不转换EXIF/IPTC。载入XMP只填当前27个手填字段，缺失字段不清除；其他字段/语言/GPS提示未导入。全部验证后核对编辑区并明确加入草稿。

当前手填字段扩为13项：新增版权x-default、XMP整数评分0至5/-1拒绝、标签文字。CSV/预设/剪贴板/XMP载入同步支持；版权保留其他语言。小数评分仅保持读取与未改原值，不开放写入。

批量日期可替换指定年/月/日/时/分/秒，留空保持每张照片自己的原值；非法日期整批拒绝，保留小数秒和固定时区。地图浏览器/渲染进程故障会提示重载，主浏览器退出后重新创建控件并保留照片、轨迹与草稿。

日期均匀分布使用相同小数秒/固定时区的起止，按当前选择顺序及最近整秒分配；短间隔可能重复，单张采用起点。预览确认后加入草稿，保存仅创建副本。

照片预览页显示当前单选JPEG/PNG，以及DNG已有的内嵌JPEG预览，最长边512像素，保留方向；多选清空。原文件外部变化拒绝，预览关闭文件流、不改图像；DNG须含可用JPEG预览且原文件不超过64MiB，不进行RAW显影；其他RAW/HEIC预览尚未开放。

当前外观：默认跟随Windows系统；应用设置可切换浅色/深色并保存本机偏好，重启恢复；缺失配置时跟随系统。地图网页样式独立。

批量日期另支持文件名正则捕获组＋日期模板，逐项跳过不匹配/非法日期；仅设置XMP拍摄时间，先预览再加草稿/保存副本。普通捕获组可用，前后查找/反向引用不支持。

字段剪贴板页另提供GPS坐标复制/预览：单张来源、WGS-84经纬度，先选择目标再预览，地图核对后加入GPS草稿/保存副本；不包含海拔/时间/地区。未知海拔/测量时间清除旧XMP值，其他字段保持原保存范围。Mac定位剪贴板互导未验。

设备字段只写XMP-tiff:Make/Model与XMP-aux:Lens/LensSerialNumber；原EXIF设备信息保留。序列号按文字保存，前导零保留。

新增数字化时间、创建时间、修改时间（XMP）；复用拍摄时间格式与校验，各项分别勾选，批量日期只调整拍摄时间。

曝光参数新增XMP曝光时间、光圈、ISO、焦距、曝光补偿、曝光程序、白平衡。可用小数或分数，草稿转换为标准数值；ISO/程序/白平衡须为整数，范围与Mac现有约定一致。只写XMP，原EXIF曝光信息保留。当前手填27项。
