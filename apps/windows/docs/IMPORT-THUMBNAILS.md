# R06a 导入、缩略图与地图照片条

2026-10-14。本批实现及定向验证独立记录，R05本地完成与随后补齐远端同步分开；R06a待用户验收，不代表全产品或全格式完成。

文件选择、文件夹、拖放与命令行的照片输入共用后台枚举。递归及同目录JPG／RAW配对默认开启，本端v1设置保存开关；旧配置没有新键时使用默认，已保存false保持。开关只作用下一次导入，当前队列及既有组不重组。正在导入时重复入口不创建第二队列；安全结束后可继续导入。拖放／命令行目录仍保留原有当前层轨迹入口，不将照片递归升级为轨迹算法。

目录流式遍历，不跟随目录或文件重解析点。当前普通本机固定卷读取，网络／设备及身份无法证明的来源显式拒绝。大小写、重叠根目录、点路径别名和同物理文件按完整路径与Windows文件身份去重；硬链接别名不重复进入写入集合，原位仍沿旧硬链接拒绝。身份集合每轮最多100000项，目录深度128，等待64项，读取最多16文件一批；不是照搬Mac32任务常量。权限／目录枚举失败、单文件失败、类型不符、跳过和取消分别计数；错误摘要最多50条，数量不截断。

候选冻结文件身份、长度、创建／修改时间及原生ChangeTime；读取复用LoadBatchAsync、完整检查器与共享日期，接纳前再查身份、实际字节与XMP来源关系。完整来源或日期尚未准备成功不进入可写集合。枚举总数未知时只显示已发现／当前读取／已读／已接纳／等待数量，没有假百分比。等待列表选中可将该项移到下一批前部；已开始读取安全完成。暂停停止新批及接纳，继续沿原队列重核；保存／应用期间同样暂停等待工作，结束后按当前版本继续。取消保留已接纳与原有草稿，不接纳迟到结果。关闭等待当前准备安全结束。队列、照片会话与缓存仅当前运行内保留。

JPG／RAW展示组仅限同目录同主体、已支持扩展名且真实FileType相符的一JPEG与一RAW；多个候选标明歧义并全部保留。JPEG标为主视图，Windows原生分组中仍可分别选择RAW成员以查看其独立元数据，避免把JPEG编辑资格传播给RAW；不是Mac只呈现JPEG并隐含成对写入的保存范围。后续新成员不替换已有对象、草稿或来源证明，关闭配对不拆旧组。XMP实际来源配对独立，独立XMP仍进入业务集合；同XMP作为多个成员来源或独立输入的写入目标冲突继续由既有路径规范化及SavePlan拒绝；本机短文件别名展开后同样拒绝。分组不自动选择或修改其他成员，不扩展副本／原位／新旁车白名单。

列表最长边约80逻辑点×实际DPI；地图条按实际宽度×DPI取160／256／384／512／768／1024档；大预览固定最长边1024像素。尺寸和方向仅显示，不旋转或改写照片字节。小图与大图独立缓存，各最多384项／64MiB估算解码预算；按实际输出尺寸、至少32bpp并为转换底图保留双份估算，比Mac单份像素估算保守。预算不是进程总内存，画面持有、排队消费者和正在解码另计。

加载键含路径／SHA／物理身份与实际属性／ChangeTime版本、方向、规格及DPI；两路本地解码，当前大预览优先等待小图。同键请求合并，一消费者取消不终止其他消费者；无消费者的等待任务取消，已启动任务安全结束。快速切换、回收控件、移除、源更新或DPI改变使旧请求不再接纳。热缓存不解码，不在布局getter读取文件或启动进程；保存不会无条件清空全缓存。外部属性版本变化显示不可用，须沿现有显式重读核对，不能自动把新源绑定到旧草稿。

列表与地图底部条使用同一CollectionView及稳定照片集合，复用筛选／排序；扩展多选及隐藏范围按既有规则。点击照片条沿既有输入放弃确认和选择链，不另建业务集合、不调用地图定位或GPS草稿。“回到当前”只滚动两个列表，当前项不可见时说明原因，不清筛选、不改选择或地图视野。RAW成员使用自身来源；不以JPEG缩略图冒充RAW解码支持。

源读取失败保留旧完整快照并标失败，计数不会替换为零，字段写入资格仍由实际来源检查控制。R02重读、R03/R04副本／原位／恢复、R05完整冻结及一次撤销保持。新非平凡边界检查在DateHost/UiChecks的R06a定向入口；单次1／20／100及较大合成目录性能独立归属，不覆盖旧性能结果。

原深路径Win32=206、旧备份异常、遗留IPTC编码、TxF未来可用性、旧3.82秒、GPS清空回退、无SDK部署／许可NOTICE／SwiftPM14001及其他原未验保留。未实现R06b新格式解码、撤销移除、跨启动照片会话恢复、地图服务／收藏或照片GPX；不恢复自动化。

选择确认／请求失效同步执行；显示刷新在WPF选择事务结束后合并，仅最新选择接纳。期间新输入不被覆盖，照片条来源的刷新仍不定位地图；早期候选的秒级选择停顿与测量保留历史，最终候选另列。
