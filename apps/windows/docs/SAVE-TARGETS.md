# Windows 保存目标、范围与原位恢复 · R03b

## 2026-10-13 · R03b 原位备份、回读与按记录恢复

默认仍为副本。显式“原位保存（强制备份）”只开放已验证的 JPEG、JPEG／DNG 已有 XMP 旁车及独立 XMP：无旁车 JPEG 写该 JPEG，有旁车写真实 XMP并保护原图完整 SHA，独立 XMP写自身。已完整确认的新旁车可按已有 XMP处理；关系或结果未核实的来源拒绝。无旁车 RAW／DNG图内写入不开放，继续显式新旁车。Ctrl+S仍为所选副本，全库／工作区字段范围和副本保留草稿语义不变。

先选已存在的备份目录，核对冻结摘要，再执行；准备及取消不写元数据。实际被改文件先生成唯一、不覆盖的完整字节备份并回读 SHA。保存原创建／修改／访问时间、属性、文件身份及适用安全描述符；同卷暂存沿已有完整 XMP、v2日期、非目标内容、其他语言、未知命名空间、列表及 JPEG像素保护。提交前原生句柄重新核验身份／SHA；提交后独立读取真实目标和完整来源，界面接纳成功才清除本次字段，残余草稿先证明基准仍适用。同步来源计数、日期排序、重命名筛选和地图／轨迹失效，旧撤销不再适用。

阶段记录持久保存于本机 InplaceHistory；备份无自动清理。提交后取消、回读／日志／界面接纳失败保留目标、备份、记录和旧草稿，标为待核对，禁止同目标盲写、重读重绑定及改名。启动只发现记录，不自动恢复；损坏记录保守阻止变更，其他安全读取继续。保存摘要页先“核对记录摘要”，再明确接纳已知结果或“按所选记录恢复”。恢复校验备份、路径、当前身份及已知 SHA，另存当前版本，以同卷暂存和原生替换恢复，最后真实字节／元数据／属性回读并接纳来源。外部变化、失联、占位、损坏或不匹配拒绝；重复已恢复不再写入。恢复后未完成草稿仍须重新证明，不能将新 SHA套到旧草稿。

支持边界为本机已验证、普通继承权限的固定 NTFS卷。网络卷、自定义显式 ACL、硬链接、重解析点、附加 NTFS数据流、只读／加密／压缩／稀疏目标及未验证格式保守拒绝；并发 ACL变更、真实断电／磁盘耗尽未验，访问时间可能随实际读取由文件系统更新。取消在当前文件安全节点收尾，已成功文件不整批回滚，不宣称文件与日志跨文件断电原子性。EXIF GPS回退下的 XMP坐标清空继续拒绝，保留草稿；未修改 EXIF或共同回退规则。无 SDK部署、许可／NOTICE、SwiftPM／14001仍未闭合。R03a已接受Windows代理结果，非用户亲自运行或Mac独立Windows验证；R03b候选需用户验收。

# Windows 保存目标与范围 · R03a

## 2026-10-13 · R03a 保存目标、范围与新旁车

默认副本。旧“保存所选草稿为副本”及 Ctrl+S 仍只收集所选草稿，先显示冻结摘要，再由“确认执行冻结计划”写入。新增“全部待保存”从全库收集净草稿，不依赖选择、当前可见行或筛选。“当前工作区待保存”在元数据页仅含非 GPS 字段，在地图页含成组 GPS（方法、基准、高度及测量时间清除）；重命名页不产生第三套元数据范围。未应用输入明确阻止准备，不隐式保存。副本成功保留原会话草稿。

显式选择“新建同目录 XMP 旁车”后，JPEG／DNG 无旁车照片可以用既有 XMP 白名单与 GPS 编辑入口建立草稿。DNG 的图内副本资格仍不开通；已有 RAW 草稿不能静默切回副本。按 Path.ChangeExtension(file, ".xmp") 真实配对，不是任意目录导出。已有旁车或独立 XMP 拒绝新建，后续修改使用副本路径；其他无旁车格式未验。模式／输出目标变化使旧执行资格失效。原位改写和备份恢复仍属于 R03b，界面不提供原位入口。

完整 XMP 包或合法空包保留非目标字段、其他语言、未知命名空间及列表；不转换 EXIF／IPTC。同名、大小写／路径别名及导入来源目标冲突整批拒绝，暂存、回读和 SHA／revision 复核后不覆盖交付。成功完整回读才接纳新旁车来源并清除本次已保存字段；残余草稿先证明旧基准仍适用，再原样保留。同步来源展示、计数、日期排序、重命名筛选、地图与轨迹失效，旧撤销失效。交付后失败／取消记为结果未知，保留实际文件、旧快照与草稿，禁止再次新建或盲写；明确处理草稿后手动重读恢复。

限制：原图有 EXIF GPS 时，清空新旁车 XMP 坐标不能证明屏蔽原图 GPS 回退，因此该新旁车组合拒绝并保留草稿，等待产品契约决定。明确坐标及其他字段继续支持。无 Swift SDK 部署、许可／NOTICE、SwiftPM／14001 保持未闭合。R02用户已接受代理结果；本批验证与用户验收分别记录。

GPS作为一组保存；日期经过固定 date-core-v2 验证，原文字、精确秒／纳秒、偏移不变。截图或摘要不代替文件回读。逐文件成功／失败／取消／未知／跳过分别显示。未知文件不自动清理；旧来源和草稿不能被新哈希绕过保护。本批新旁车目录链接保守拒绝，目录别名在准备阶段按真实父目录核对物理目标。
