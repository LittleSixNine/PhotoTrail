# Windows 保存目标与范围 · R03a

## 2026-10-13 · R03a 保存目标、范围与新旁车

默认副本。旧“保存所选草稿为副本”及 Ctrl+S 仍只收集所选草稿，先显示冻结摘要，再由“确认执行冻结计划”写入。新增“全部待保存”从全库收集净草稿，不依赖选择、当前可见行或筛选。“当前工作区待保存”在元数据页仅含非 GPS 字段，在地图页含成组 GPS（方法、基准、高度及测量时间清除）；重命名页不产生第三套元数据范围。未应用输入明确阻止准备，不隐式保存。副本成功保留原会话草稿。

显式选择“新建同目录 XMP 旁车”后，JPEG／DNG 无旁车照片可以用既有 XMP 白名单与 GPS 编辑入口建立草稿。DNG 的图内副本资格仍不开通；已有 RAW 草稿不能静默切回副本。按 Path.ChangeExtension(file, ".xmp") 真实配对，不是任意目录导出。已有旁车或独立 XMP 拒绝新建，后续修改使用副本路径；其他无旁车格式未验。模式／输出目标变化使旧执行资格失效。原位改写和备份恢复仍属于 R03b，界面不提供原位入口。

完整 XMP 包或合法空包保留非目标字段、其他语言、未知命名空间及列表；不转换 EXIF／IPTC。同名、大小写／路径别名及导入来源目标冲突整批拒绝，暂存、回读和 SHA／revision 复核后不覆盖交付。成功完整回读才接纳新旁车来源并清除本次已保存字段；残余草稿先证明旧基准仍适用，再原样保留。同步来源展示、计数、日期排序、重命名筛选、地图与轨迹失效，旧撤销失效。交付后失败／取消记为结果未知，保留实际文件、旧快照与草稿，禁止再次新建或盲写；明确处理草稿后手动重读恢复。

限制：原图有 EXIF GPS 时，清空新旁车 XMP 坐标不能证明屏蔽原图 GPS 回退，因此该新旁车组合拒绝并保留草稿，等待产品契约决定。明确坐标及其他字段继续支持。无 Swift SDK 部署、许可／NOTICE、SwiftPM／14001 保持未闭合。R02用户已接受代理结果；本批验证与用户验收分别记录。

GPS作为一组保存；日期经过固定 date-core-v2 验证，原文字、精确秒／纳秒、偏移不变。截图或摘要不代替文件回读。逐文件成功／失败／取消／未知／跳过分别显示。未知文件不自动清理；旧来源和草稿不能被新哈希绕过保护。本批新旁车目录链接保守拒绝，目录别名在准备阶段按真实父目录核对物理目标。
