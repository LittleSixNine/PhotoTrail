# Windows R05 日期复合预设与自身跨来源复制

R04c由用户接受Windows代理交付；R05等待用户验收。来源/类型固定Mac73c0640bca4d1a2919aa3a466487a5cb20c7f28d，有序链及缺值先验参考cbeccc015c416c6a82d02645eeb6ccfadb8cef99；源码参考不补造Mac GUI验证。固定共享date-core-v2及177行a0299e6f组合保持，不重写历法或协议。

“字段预设”保留原有编排、列表、库身份/名称保护及单次应用流程。增加五种日期动作；参数复用日期页的有符号六组件、组件选择、起止、间隔、正则和模板控件。后一步读取本次开始前已有草稿和前一步结果，同一目标可重复。清除后依赖当前时间的动作跳过；设定/补空或复制后可继续计算。每张照片读取自身源，不跨照片取值或同步同义来源。
