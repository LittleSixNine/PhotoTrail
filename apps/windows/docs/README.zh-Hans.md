# PhotoTrail Windows

### Windows 开发状态

当前Windows本地测试版支持13项常用XMP草稿、保存副本、CSV/XMP交换、批量日期（含文件名捕获）、JPEG/PNG与DNG内嵌JPEG预览、地图/轨迹与可恢复重命名；外观偏好可重启恢复。默认OpenFreeMap＋MapLibre；Google须用户自备密钥，真实API仍待验。完整字段、多语言界面、更多格式与其他电脑尚未完成，未正式发布。构建和当前范围见[Windows开发说明](../README.md)。

同一Windows会话的多个实例会合并最近轨迹路径。

GPS剪贴板只从单张照片复制坐标，选择目标核对预览后加入草稿并保存副本。不含海拔、测量时间和地区。

设备信息新增制造商、设备型号、镜头和镜头序列号；只写XMP，原EXIF保留，序列号前导零保留。当前手填27项。

当前手填27项；新增XMP数字化、创建、修改时间，各项独立，批量日期只调整拍摄时间。

当前手填27项，新增七项XMP曝光参数，支持有限数值/分数和字段范围校验，只写XMP。
