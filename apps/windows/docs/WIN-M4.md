# WIN-M4 地图、照片条与轨迹

固定 Mac build1970 的地图职责落到真实 WPF：左侧当前照片预览、位置、收藏与轨迹，右侧既有地图，底部独立照片条。左右分隔和照片条高度可拖动，窄窗可收起辅助区。五种筛选、六种排序、选择与元数据区共用实际集合。

位置预览不改草稿；明确应用以完整旧草稿登记一次撤销，净零不覆盖既有撤销。GPS、轨迹匹配、手填地区、照片生成 GPX、收藏和轨迹调整借入相关参数窗口，沿原验证与保存链。副本保存保留会话草稿并使此前撤销过期，撤销草稿不恢复落盘副本。

隐藏轨迹只停止绘制；有效含时轨迹仍参与匹配及按时段选照片。后者先复核每条来源，来源变化拒绝并保留原选择。几何轨迹与可匹配含时轨迹分开。首次没有保存视野时适配已导入轨迹，保存视野不覆盖。同坐标照片在默认地图上优先绘制所选标记。

默认提供者保持 OpenFreeMap。卫星与真实 Google、设备定位依原授权和可用环境；在线地区持久写入 D06、GPS 清除回退等独立门保持。照片 GPX 明确预览、另存回读、加入，不等同保存照片；缺主时间、偏移、基准或精度资格分别跳过。

本阶段检查与原生证据分属记录；测试版不是正式可分发包或用户验收。六类设置、引导和语言进入连续任务下一阶段。
