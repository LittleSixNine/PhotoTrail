有净变化才提交；先替换全批草稿，再发送各照片的既有通知，观察者不会看到半批。统计分别列修改／无变化照片数、净变化字段操作数、缺失时间／文件名不匹配／文件名日期无效项数及CSV身份跳过行／未知列数；无变化照片包括整张没有净修改的跳过照片，不能与操作数相加。错误不归缺值跳过。失败保留编辑输入；无变化不清空地图定位预览，不覆盖有效撤销。

工具栏“撤销最近一次应用”恢复该批之前的完整草稿，保留更早编辑；限会话内最近一批。保存、重新载入或该批之后的草稿变动使过期撤销失效；撤销不会去掉后来编辑。“清空所选全部草稿”是另一个明确操作。应用结果区保留最近成功应用统计，当前草稿以上方数量与保存按钮为准。原文件只读，显式保存副本才写文件，既有备份、不覆盖及回读保护保留。

# PhotoTrail Windows

## Windows 开发原型（2026-10-09）

本文件仅记录 Windows 行为；Mac 约定见仓库根目录的 docs/BEHAVIOR.md。Windows 原型位于 `apps/windows`，现有阶段只支持导入／读取、五项 XMP 草稿与保存副本，以及地图坐标预览。Windows 原型未达到完整应用功能及发布验收。

导入支持文件多选、拖入和当前层文件夹；不递归。XMP 使用已有同名旁车优先，内嵌和旁车原始字段分别显示。JPEG／XMP 支持编辑作者、标题、说明、关键词、XMP 拍摄时间；列出的 RAW／图像格式仅在已有旁车时编辑旁车，其余只读。标题／说明只改 x-default，列表按换行分项，时间使用 yyyy:MM:dd HH:mm:ss 可附时区，暂不支持亚秒。多选只应用勾选字段；勾选且留空表示清除，混合值不自动清除。加入草稿不写文件，撤销恢复源值。

保存只写选中照片的副本，输出文件夹须已存在，同名文件拒绝覆盖；有旁车时复制原图与旁车并只写副本旁车。回读目标与非目标元数据并验证原图、JPEG 像素载荷不变。源文件版本改变时拒绝保存。逐张处理，失败保留草稿，取消保留已完成副本；保存成功仍保留源草稿供撤销。关闭时保护未应用输入及草稿，正在运行的任务先取消并等待结束。

默认地图为 OpenFreeMap＋MapLibre，当前点击只预览 WGS84；未实现照片 GPS 写入、地址解析、轨迹、Google 自备密钥入口、重命名、照片图库或 macOS 设置。构建和验证见 [Windows 说明](../README.md)。

## 阶段3本地地图与轨迹增量

支持GPX／KML／KMZ轨迹导入、选择、移除及图层显示。轨迹只在本机解析；文件中的链接、样式、图片不加载。KMZ只在内存读取主KML，不向磁盘展开；主文档、路径、重复名称、体积、条目数及压缩比例有检查。

轨迹匹配沿用元数据页照片选择，要求明确带时区的ISO8601时间；XMP拍摄时间已带偏移时自动填入，缺少时区不猜测。精确点优先，同段有时间相邻点插值，不跨段／无时间点、不外推，多位置歧义不自动定位。KML无逐点时间只显示；相对地面高度不写作海拔。地图轨迹跨日期变更线时分线显示。

选点和匹配先预览，再显式加入所选可编辑照片的GPS草稿。写入XMP-exif的GPSLatitude、GPSLongitude、GPSMapDatum=WGS-84和GPSProcessingMethod（匹配GPS，点选MANUAL）；已知海拔写入GPSAltitude与GPSAltitudeRef，未知海拔清除旧XMP海拔。旧XMP GPSDateTime清除，不从照片时间猜测测量时间。经纬度保留8位小数；GPS回读容差1e-8。EXIF/IPTC保留，原文件只读，继续经共用保存入口另存副本。

照片标记显示XMP／草稿定位，缺少XMP定位时回退EXIF。基准缺失只暂按WGS84显示，不补写；明确其他基准不显示。点击照片标记同步选中条目，图层版本号防止旧消息选择重排后的其他照片。修改、撤销、导入和移除更新图层，原文件不删除。

当前默认OpenFreeMap真实预览与GPS副本链路已验；Google地图渲染、地区解析和断网/重建等仍待开发/验收，未完成整个阶段3。底图按当前视野联网请求，照片文件及本地轨迹几何不作为上传内容；默认地图不提供逆地理解析。

预览标记可拖动；照片图层本身仍为选择入口。拖动产生手动WGS84位置预览，清除轨迹匹配海拔；不自动加入草稿或保存。跨日期变更线的位置归一至±180度，非法/非有限坐标不向宿主发送。

手动点选或拖动后，匹配结果区域立即显示当前手动坐标、未知海拔和未加入草稿状态，不继续显示旧轨迹匹配位置。

地图页提供“重载地图”：底图加载失败后可重新加载页面，保留照片、当前轨迹、GPS/字段草稿及位置预览；新页面就绪后重放图层。任务及地图初始化期间禁用重载。在线重载和样式加载失败后的恢复已实机验证；持续离线、浏览器进程退出与初始化超时恢复仍待验。

地图加载错误会同时显示于网页及原生底部状态；任务进行时保留任务进度。错误消息仅含固定类型，不传递请求地址或异常原文。

地图设置页已提供Google密钥本机保存/删除（接入准备），使用Windows当前用户DPAPI保护，不回显已存内容，保存后清空输入；保存不联网验证。默认仍为OpenFreeMap，Google地图渲染与地址解析尚未接入。密钥格式限制20至256位英文字母/数字/横线/下划线。更换电脑或Windows用户后重新输入；同用户进程仍可能解密，不能替代Google限制/配额。

Google入口使用受限本地页面，只有明确点击使用Google才解密并注入网页SDK；默认每次启动OpenFreeMap。查询当前位置由单独按钮触发，20秒超时、请求版本与坐标防止旧结果回写。结果标识Google Maps，仅当前预览，不自动写照片或日志。Google结果持久写入的许可适用性仍待核实，参见 https://developers.google.com/maps/documentation/geocoding/policies 。

手填国家、省/州、城市、区/地点与三字母国家码写XMP-photoshop Country/State/City和XMP-iptcCore Location/CountryCode，最多256字且无控制字符。原IPTC/EXIF保留；勾选留空才清除，未勾选字段不改。

重命名页沿用所选照片，规则逐行从上到下作用于主名，保留扩展名，支持前缀/后缀/替换/设名/大小写/序号。可按名称排序；即时名称预览不改文件，检查冲突/内容哈希后冻结，改规则或选择使计划失效。有草稿/未应用输入/导入后外部变动/新旁车时不执行。

执行先全部暂存再落最终名，不覆盖其他文件。已核验Windows句柄禁止外部写/移，逐步记录且更名后再核验SHA256。执行中取消/失败保留每项实际名称和执行记录；按记录恢复核验内容，恢复也生成记录，可按该记录撤销恢复。部分更名恢复前暂停元数据编辑，避免旁车暂存关系误写。最近记录在重启后回读；损坏/变化的记录或文件不强行恢复。

## CSV草稿交换

CSV页作用于元数据页当前选择，最多3000文件、输入8MiB。回导PhotoTrail CSV 1的标题/说明列使用-x-default，值为JSON字符串，作者/关键词为JSON数组；空单元不修改，@clear明确清除，JSON字符串"@clear"表示字面值。身份为当前绝对路径UTF8的SHA256，RelativePath须精确对应当前选择；跨机器/移动路径不能直接回导。不依CSV路径打开其他图片。重复身份、路径、列或错误行长度拒绝整个输入；非法值／错误类型拒绝整批，未知字段提示忽略。只开放既有手填XMP字段，Google结果及GPS不导出。一次应用读取并校验身份／冲突，终态再复核全选择来源与草稿；保存仅副本。

显示CSV把危险公式前缀文本和路径加单引号，不能回导。回导CSV保持JSON值，并拒绝公式前缀相对路径；使用显示格式或先安全重命名。CSV导出通过同目录自建临时文件落盘后更名，已有目标不覆盖。

## 批量日期

元数据页的批量日期仅改XMP拍摄时间。调整各自当前值或按当前选择顺序生成固定间隔序列，一次应用加入草稿，保存仍为副本；缺失/非法日期不猜测，偏移拒绝整个应用。年/月/日/时/分/秒依次调整，闰日/31日落入非法日期拒绝，不夹到月末。保留1至9位小数秒和Z/±hh:mm，无时区保持墙钟值；不处理时区夏令时转换。日期改变或撤销刷新匹配时间，只有明确时区且精度可由.NET精确表示时自动提供轨迹时间；亚100ns非零尾数需明确输入匹配时间。

## 字段预设

编辑草稿页勾选字段可保存为JSON预设；已有目标不覆盖。载入需要可编辑选择且无尚未应用输入，只填入编辑区并勾选预设字段，用户核对后一次应用；原有草稿不会被自动清空。当前支持既有27个手填字段替换/清除，version1/name/operations形状及标题说明-x-default别名沿用Mac，真实双向互导尚待验。名称1至80字、1至10操作、128KiB；重复或未知字段/操作完整拒绝，不执行部分预设。关键词精确字符去重，作者保留顺序和重复；不支持列表空项/内部换行。复杂追加/日期链等留待对齐。

## 字段剪贴板

元数据页字段剪贴板明确选择源字段，复制所选照片当前原值（包含草稿）；缺失、混合、NUL或超过8192字不复制为单值。仅按钮触发剪贴板读取，不监听。粘贴作用于编辑草稿页当前勾选的既有手填字段，先完整验证全部目标，再把同一字面值填入编辑区；非法日期/国家码/地区不改任何输入。用户再核对并明确加入草稿，最后保存副本；不直接写照片。CRLF统一为LF，日期不转换显示时区，作者/关键词按换行分项。文本框原生Ctrl+C/V保持原焦点行为；GPS/完整字段剪贴板尚未开放。

## 批量导入增量

导入按最多32主文件/64物理文件批次读取，去重使用路径集合，回执按SourceFile身份映射，不能按返回顺序错配；单张回退也核对身份。坏命令逐张隔离，取消保留已完成批次。主图/旁车前后哈希及旁车关系检查保留；新出现旁车、伪装图像旁车、ExifTool明确报告JPEG format error的损坏结构拒绝。CLI启动可传当前层文件夹，读取失败进入状态提示，不递归。

文件名搜索忽略大小写；全部、有草稿、无草稿与名称升降序作用于会话视图，不移除隐藏文件或草稿。草稿应用/撤销后重新筛选；未应用输入时拒绝视图变更，任务中禁用。总草稿数包含隐藏项。

Windows重命名规则JSON包含version1、rules和sortByName；64KiB上限，未知/重复属性和无效规则完整拒绝。保存保留当前输入，载入使冻结计划失效，重新检查冲突后才能执行。

最近轨迹最多20个绝对路径，本机JSON保存在Windows用户应用数据中，不保存坐标、不自动加载。读取损坏历史不自动覆盖；历史中的失效路径在手动重新读取时报告失败。会话移除不删除历史或轨迹文件；同一Windows会话的实例保存时串行读取最新历史并合并，保留最近20项；等待锁最多5秒，失败保留已导入轨迹并提示历史未保存。文件替换允许读者完成原快照。跨Windows会话合并/清除入口尚未开放。

历史重新读取已在会话中的同路径轨迹也会重新解析；成功后替换数据并使旧匹配预览失效。失败保留会话旧轨迹并明确提示，不能视作本次回读成功；普通重复导入仍跳过。

Windows快捷键沿已有入口：Ctrl+O照片、Ctrl+Shift+O文件夹、Ctrl+S副本保存、F3文件名搜索、任务/环境检查中Esc取消。保存仍拒绝未应用输入，无自动加入/原位写入。网页内部焦点路由尚未验。

保存副本前后核验原图/已有旁车内容及旁车关系；导入后新出现同名XMP须重新导入，不能沿旧内嵌来源保存。写元数据前暂存副本SHA必须与导入基线一致。

XMP交换：单文件完整现有包（旁车优先）加冻结草稿另存，保留原文件，拒绝覆盖；没有XMP时从空包开始，不把EXIF/IPTC迁移进XMP。载入仅当前10手填字段，缺失字段保持、其他标签显示未导入；8MiB、禁DTD/外部实体，非法字段整批拒绝，需明确加入草稿后再保存副本。

当前13手填字段增加XMP-dc:Rights（只写x-default）、XMP-xmp:Rating（0至5整数/-1拒绝/空清除）、XMP-xmp:Label（256字无控制字符）。CSV、字段预设、剪贴板、XMP载入同范围。已有小数评分仅读取/未改保留；严格UTF8拒绝孤立代理项，其他语言版权继续保留。

地图主浏览器退出后显示故障状态；点击重载会创建新WebView2控件。页面渲染进程退出或无响应时点击重载重新导航。照片、选择、轨迹与草稿保留；只重建地图，不自动保存照片或重新查询地区。GPU/工具进程自动恢复交由WebView2处理。

批量日期可选择替换年/月/日/时/分/秒：留空保留每张照片各自原组件，0只允许时/分/秒；至少指定一项。保留原小数秒和固定时区，不生成缺失日期；任何非法组合整批预览拒绝，不自动把闰日或31日截为其他日期。预览后明确加入草稿，改输入使旧预览失效。

日期均匀分布按照当前选择顺序，在明确起止之间按最近整秒分配（半秒向后），保留首尾。起止的小数秒和固定时区文字须完全相同；不做时区换算。间隔过短可出现相同时间，单张使用起点；仍预览后加入草稿。

照片列表可筛选有/无可用定位，复用当前照片坐标（包含GPS草稿），不联网查地址。越界/非法坐标或不支持的基准不算可用定位；隐藏项和草稿仍保留。GPS草稿应用/撤销后动态更新可见列表。筛选导致照片隐藏时选择会移出当前可见列表，须恢复全部再选择操作。

照片预览页仅本机读取当前单选JPEG/PNG或DNG内嵌JPEG，不改原文件。只保留当前一张图像，后台串行解码，快速切换取消旧等待且拒绝迟到结果；多选清空预览。输入最大64MiB/一亿像素，预览最长边512像素，遵照EXIF方向旋转/镜像；载入核对导入SHA，外部变化拒绝。原生OnLoad后关闭文件流，不妨碍随后保存副本或重命名。DNG经既有ExifTool提取PreviewImage到随机临时JPEG，源文件读取期间拒绝外部写入；复用JPEG尺寸/方向校验，结束或失败后清理临时预览。缺少/损坏的内嵌JPEG明确拒绝，不进行RAW显影。其他RAW/HEIC等仍可读取元数据，预览未开放。
