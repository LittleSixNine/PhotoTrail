# WIN-M6 局部收尾

2026-10-16，固定Mac build1970/cbeccc015c416c6a82d02645eeb6ccfadb8cef99；公开资格起点b48d84c672c144f2e6f5b6b0968375dd5e783fe3。仅调整Windows WPF界面及相关检查，不改变共享日期、DateHost、保存、恢复或互导支持契约。M2—M6待用户验收；本节点不是发布。

## 用户可见修正

- 重命名默认显示启停、名称和参数摘要；点击展开当前规则，其他规则收起。卡片“⋯”提供查看步骤、复制、删除与排序；Alt+↑↓处理WPF的SystemKey，实际键盘重排可用。收起不等于停用。
- 任务设置中的九个标签和输入逐行对应，窄窗口及大字号仍保留输入与局部滚动，筛选计算与查看范围不变。
- 矮或窄地图窗口保留照片面板、照片条和地图工具明显入口。默认窗保持左右区与底部照片条；紧凑窗自动收起照片条，用户可重新展开，地图的选择、轨迹集合和位置预览不变。
- 元数据铅笔使用所在DataGridCell前景，随活动／失焦选择着色；只读与禁用资格不变。
- 错误提示显示当前规则序号、名称、参数、合法要求及保留的错误文本。“定位首个错误”展开对应卡片；无效输入继续拒绝冻结、执行和保存无效方案，复用原模型校验。
