## M8 / M9

M8/M9 개발 후보: 순서가 있는 이름 변경 페어링과 날짜 출처, 엄격한 프리셋 변환, 세션 카메라 시간대, 전체/현재 페이지 저장, 실행 취소 가능한 지도 편집을 제공합니다. 위치 지우기는 검증된 JPEG/JPEG+XMP 사본으로 제한됩니다. 사본 저장 후에도 초안은 유지됩니다. 서비스, 형식, 접근성 환경 및 사용자 승인은 아직 확인되지 않았습니다.
