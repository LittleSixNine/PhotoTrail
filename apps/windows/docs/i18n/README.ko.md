# PhotoTrail Windows

### Windows 개발 현황

Windows 로컬 테스트 버전은 일반 XMP 27개 필드, 사본 저장, CSV/XMP 교환, 파일명 날짜 추출을 포함한 일괄 날짜 편집, JPEG/PNG 및 DNG 내장 JPEG 미리보기, 지도·트랙 및 복구 가능한 이름 변경을 지원합니다. 외관 설정은 다시 시작해도 유지됩니다. 기본 지도는 OpenFreeMap＋MapLibre이며 Google은 사용자 API 키가 필요하고 실제 API 검증은 대기 중입니다. 전체 필드, UI 번역, 추가 형식 및 다른 PC 검증은 아직 완료되지 않았고 정식 출시되지 않았습니다. [개발 안내](../../README.md)를 참조하세요.

같은 Windows 세션의 여러 인스턴스에서 최근 트랙 경로를 병합합니다.

GPS 클립보드는 사진 한 장의 좌표만 복사합니다. 대상을 선택하고 미리보기를 확인한 뒤 GPS 초안에 추가하여 사본을 저장합니다. 고도, 측정 시간, 지역 정보는 포함하지 않습니다.

제조사, 모델, 렌즈, 렌즈 일련번호를 XMP로 편집할 수 있습니다. 원본 EXIF 장비 정보와 일련번호 앞자리 0은 유지됩니다.

XMP 디지털화·생성·수정 시간을 각각 편집할 수 있으며, 일괄 날짜 기능은 촬영 시간만 변경합니다.

XMP 노출 정보 7개를 검증된 숫자나 분수로 편집할 수 있으며 원본 EXIF 노출 정보는 유지됩니다. 수동 필드는 27개입니다.
