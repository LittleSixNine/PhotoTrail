# PhotoTrail Windows

### Windows 開発状況

Windowsのローカルテスト版は、よく使う27項目のXMP、コピー保存、CSV/XMP交換、ファイル名からの日時抽出を含む一括日時編集、JPEG/PNGおよびDNG内蔵JPEGプレビュー、地図・軌跡、復元可能な名前変更に対応しています。外観設定は再起動後も復元します。標準地図はOpenFreeMap＋MapLibreです。Googleは利用者のAPIキーが必要で、実APIの検証は未完了です。全項目、画面の多言語化、追加形式、他PCでの検証は未完了で、正式公開していません。[開発説明](../../README.md)を参照してください。

同じWindowsセッションの複数インスタンス間で最近の軌跡パスを統合します。

GPSクリップボードは1枚の写真から座標のみをコピーします。対象を選択してプレビューを確認し、GPS下書きに追加してコピー保存します。標高、測定時刻、地域は含みません。

メーカー、機種、レンズ、レンズのシリアル番号をXMPとして編集できます。元のEXIF機器情報は保持し、シリアル番号の先頭のゼロも保持します。

XMPのデジタル化・作成・変更日時を個別に編集できます。一括日時操作は撮影日時のみを変更します。

XMPの露出情報7項目を数値または分数で編集できます。元のEXIF露出情報は保持します。手動項目は27です。
