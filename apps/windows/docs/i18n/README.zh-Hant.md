# PhotoTrail Windows

### Windows 開發狀態

目前Windows本機測試版支援27項常用XMP草稿、儲存副本、CSV/XMP交換、批次日期（含檔名擷取）、JPEG/PNG與DNG內嵌JPEG預覽、地圖／軌跡與可還原重新命名；外觀偏好可於重新啟動後還原。預設OpenFreeMap＋MapLibre；Google須使用者自備金鑰，真實API仍待驗證。完整欄位、多語介面、更多格式與其他電腦尚未完成，未正式發布。建置與目前範圍見[Windows開發說明](../../README.md)。

同一Windows工作階段的多個實例會合併最近軌跡路徑。

GPS剪貼簿只從單張照片複製座標；選擇目標並核對預覽後加入GPS草稿、儲存副本。不含海拔、測量時間與地區。

新增製造商、設備型號、鏡頭與鏡頭序列號XMP編輯；原EXIF設備欄位保留，序列號前導零保留。

新增XMP數位化、建立、修改時間，各項獨立；批量日期只調整拍攝時間。

新增七項XMP曝光參數，支援有限數值/分數與欄位範圍檢查；原EXIF保留，目前手填27項。
