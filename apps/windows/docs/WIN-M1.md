# WIN-M1：Mac 工作流对齐

Windows 开发候选以 Mac 0.5.10/build1970、固定行为提交 `cbeccc015c416c6a82d02645eeb6ccfadb8cef99` 为结构参考。仍使用 WPF、现有地图和 R10 数据保护链；本批不是全产品复刻完成或用户验收。

主窗口顺序为“元数据编辑、地图定位、重命名”。设置通过右上角独立窗口打开。地图、重命名先接入现有真实内容，内部布局后续分批对齐；设置六类完整布局也不在 M1 内。

元数据页默认两栏，可拖动中间分隔。左侧为文件名搜索、排序、筛选及照片表，支持 Ctrl/Shift 多选，显示状态、缩略图、文件名、原标签数和净草稿字段数。“照片操作”侧栏默认收起，包含收藏、轨迹匹配、日期、照片 GPX、GPS 副本和会话撤销等现有入口。

右侧检查器提供常用/完整字段、完整分组及名称/标签/值搜索。每行显示精确来源、当前值、缺失/混合/过期/草稿状态和编辑资格。双击可编辑行、按 Enter 或点铅笔打开现有真实字段编辑窗口；多选字段可用底部“编辑所选字段”进入同一编辑器。只读锁不授予写入资格。完整操作卡、比较交换和预设库的视觉重做留后续阶段。

“批量操作”及“更多”打开现有日期、字段预设、比较、剪贴板、CSV/XMP、照片预览及保存摘要。导入文件夹、递归、配对、暂停准备、重读、移除和撤销仍有真实入口；递归/配对保留在独立设置内。主工具区仅常驻导入、保存、导航和真实任务/取消状态。

直接应用只建立草稿；一次撤销恢复该次应用前草稿，并同步日期提示、逐图计数、全局计数和保存资格。没有净变化不显示为本次应用成功。取消未应用字段输入不写文件。未经应用的勾选或文本修改受选择、移除和退出保护。

主保存和 Ctrl+S 默认为所选副本；“更多”保留全库、当前工作区及保存/恢复摘要。副本、新旁车、原位强制备份及按记录恢复继续复用既有检查。保存副本保留会话草稿；撤销应用/清除草稿不会删除已经保存的文件。冻结、SHA、身份、属性、ACL、revision 和恢复保护保持。

窗口默认接近 1180×700 DIP 客户区；窄窗口工具动作换行，分栏可调，字段列表局部滚动。支持最小 720×480 外框，不能将默认大小或单一 DPI 验证当作全环境通过。

新界面文字位于 `PhotoTrail.Windows/Resources/M1Strings.xaml`，复用现有字号、密度及主题偏好。其他原有文案及全量语言资源整理留后续；不新增依赖或组件框架。

Mac Photos、Apple/高德专用服务没有迁入。D06、真实 Google/设备定位、词性/音乐、GPS 清空、其他 RAW/HEIC、实际双端互导、部署许可及历史 unknown 仍分别受原边界约束。
