## 来源与编码

EXIF、XMP、IPTC 同义字段独立。读取失败、缺失、混合值与编码不支持分别显示，不因显示而自动产生草稿。只有无旁车、没有切到新旁车编辑的已支持 JPEG 可编辑这十二个图内目标。已有旁车原图 IPTC 为只读参考；不能把 IPTC 写进 XMP，也不扩展 RAW 或其他格式图内写入。

真正无 IPTC 的首次设置增加标准 `CodedCharacterSet=UTF8`（原始声明字节 ESC `%G`）。已有数据集，包括只有 RecordVersion 的情况，只有唯一明确 UTF8 声明才允许设置／追加／补空。未声明 ASCII、其他编码、未知或冲突声明都整次拒绝设置；混合清除与不允许设置不能部分落地，独立无关 XMP／EXIF 操作仍可执行。编码声明不是用户、CSV 或预设可编辑标签，没有隐式全块迁移。

纯清除不指定 IPTC 解码／重编码、不改编码声明；保存后必须证明剩余原始 IIM 数据集字节及重复项顺序不变。JPEG Photoshop/IIM 结构不可解析、重复真实标量来源、多个 IPTC 块、工具警告或任何未证明资源改变均拒绝交付。不能据此称为所有遗留编码的无条件删除支持。

ExifTool 首次新建可生成 Envelope/Application `RecordVersion=4`；只允许缺失版本在设置时生成唯一的原始字节 `00 04`。纯删除最后一个应用字段时保留既有 ApplicationRecordVersion 的原字节，避免工具顺带删除它。数据集在块中的物理排列可重建，重复数据集内部顺序及完整原始记录字节必须保持。IPTC 单独修改若引起 ExifTool 的缩略图绝对偏移变化，必须证明 EXIF APP1 原始载荷与缩略图实际字节完全相同；不改变 EXIF 内部指针或内容。其他 Photoshop 资源逐字节保留，包括 IPTC digest；本批没有自动修正已有摘要值。若工具改变摘要／其他资源而无法证明，安全拒绝，不排除整个 APP13 或家族保护。

默认副本、Ctrl+S 所选、全库／工作区范围、主时间及三个 EXIF 日期组不变。草稿与计划绑定完整来源 SHA、编码及 revision，应用和提交前再核对。UTF8 值文件传参，工具警告拒绝；实际目标独立回读目标原字节、列表、声明、完整非目标实例、其他语言／命名空间、日期组、JPEG 主像素和缩略图载荷。

副本成功保留原草稿；原位使用强制完整备份、同卷暂存、真实回读、持久阶段和 UI 接纳，只清已证明字段，残余草稿复核旧基准。按记录恢复保留恢复前版本，核对完整原 SHA、元数据、编码与像素。读取／日志／UI 失败保持 unknown 及禁止盲重试。损坏历史记录不视作无事务，不修复清理。
