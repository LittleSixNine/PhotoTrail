# WIN-M5 设置、引导与语言

设置保持独立窗口，按固定 Mac build1970 的顺序组织为通用、地图、元数据、照片与保存、轨迹、存储。已有主题、字段配置、导入、地图及保存入口复用原处理程序；设置窗口关闭不会隐式应用照片编辑。

通用可保存启动工作区（含上次工作区）、坐标显示格式、隐藏不可编辑文件、界面语言及新会话相机显示时区。外观、元数据字号／行距和常用字段沿原偏好。恢复显示默认值只重置显示、排序、字段视图与搜索记录开关，保留备份目录、导入配对选项、上次预设和其他数据。帮助／反馈打开现有公开文档或问题页；开发候选没有自动更新安装器。

相机时区只在下次新会话用于已证明绝对时刻的显示；不修改日期值、固定偏移、亚秒、来源资格或缺少时区的匹配规则。没有偏移的日期不会因为选择显示时区而获得 GPS／GPX 时间资格。

轨迹颜色、线宽（0 使用既有默认值）、最大匹配点间隔和照片 GPX 默认断段间隔经校验后明确应用。匹配请求冻结间隔值，设置变化使旧结果失效。GPX 默认值按分钟设置，支持 5／15／30／60 分钟及自定义；下次启动用于新生成窗口，当前临时参数保持。默认间隔须大于 0、不超过 1,000,000 分钟且可精确到 100ns；临时生成参数仍沿原生产校验，不由设置页放宽。

存储摘要在后台读取轨迹来源及备份大小，递归统计备份并跳过链接；不可读取时明确报告，不能把失败当作零。7／30／90 天或关闭提醒只影响摘要提示，不自动删除备份、原轨迹、历史或 unknown 材料。Windows 没有高德转换缓存，不提供无作用的清理按钮。原位保存仍强制备份，默认副本与 Ctrl+S 所选副本保持。

四步引导为语言、保护原始照片、地图服务、准备开始。仅新空环境自动打开，也可从设置重新查看；返回和取消保留既有配置。完成才保存引导语言与完成状态。地图步骤可保留当前配置，或在完成后打开真实地图设置；不会因此自动启用 Google、保存密钥或请求服务。Google 仍需用户自行合法配置并明确使用，启动默认 OpenFreeMap。地图采用位置仍经现有预览／明确加入 GPS 草稿／保存链。

支持简体中文、英语、繁体中文、日语、韩语、西班牙语、巴西葡萄牙语和跟随系统。更改语言保存为下一次启动偏好；当前草稿和未应用输入不会因切换语言而关闭或丢弃。界面资源、动作说明、菜单、生成状态、错误／确认和应用提供的文件框类型说明使用本端资源；系统窗口仍受 Windows 自身语言影响。

动作／字段 ID、精确来源标签、CSV／XMP／JSON、数字机器表示及旧规则命令不随界面语言改变。照片值、文件名、既有预设／方案名称保持用户数据原文；仅新建时的默认名称随界面语言生成。文件类型说明可翻译，通配符和过滤顺序保持。第三方诊断及用户提供的内容不能当作缺资源后自动翻译。

Windows 保持 WPF 和现有地图方案；不引入 Mac 专用服务、更新器、关闭原位备份开关或在线永久写入许可。D06、真实 Google／设备定位、旧恢复 unknown、格式、互导及部署许可等独立门仍需分别验证。自动检查、原生操作、用户验收及正式发布是不同状态。
