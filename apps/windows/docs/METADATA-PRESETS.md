# Windows 元数据预设库

在“字段预设”编排操作后，“保存为新预设”增加本机条目，同名拒绝；“更新当前预设”更新所选条目并保留身份。列表选择只载入编辑链，须明确“应用”才加入照片草稿。无照片也可管理；空链不能保存。

复制、改名、导出读取已保存版本，保留未保存编辑；复制使用最小可用数字名（原名 2、原名 3），身份独立。改名仅改变保存项名称与必要的干净编辑名称，操作和位置不变；脏编辑链保留。名称先去首尾空白，1—80 个 UTF-16 代码单元，无控制字符；按精确、区分大小写比较，不套用重命名方案规则。删除默认不确认，仅删除所选库条目；正在编辑的链保留为未保存。

未编排参数须添加、更新或明确放弃。替换编辑链（选择、新建、导入、旧文件载入、重新读取）遇到未保存链时提示保存／放弃／取消，默认取消；保存失败保留编辑。退出默认继续编辑；明确放弃退出也不写库。照片草稿的既有退出保护独立保留。忙碌期间管理和参数冲突入口禁用。

启动只恢复列表，不选择最后条目、不恢复未保存链、草稿或应用资格。无文件首次显示空库；删空后保持空库，无种子、无默认模板、无自动迁移或旧 JSON 扫描。

## 存储与文件

本机路径为 LocalApplicationData/PhotoTrail/Windows/metadata-presets-v1.json。库外层为 format=phototrail-windows-metadata-preset-library、version=1、entries 数组，每项有稳定非空 GUID id 与 preset。保存保留顺序；最多256项，严格 UTF-8，总文件最多1MiB。拒绝未知／重复属性、未知版本、重复身份、精确名称碰撞、非法单条内容。损坏／读取失败保留原件并报错，库管理不可用；只能明确重新读取，不清空修复。

单条 JSON 继续 version=1/name/operations；operations 为有序数组，重复目标可存在，最多27条、UTF-8最多128KiB，保留既有27字段与10动作及参数限制。不导出内部身份、配置或路径。导入完整解码后处理编辑保护，成功持久化后才增加并载入；同名自动数字避让。系统取消和失败不提前入库。导出所选保存项；当前链用“保存操作链 JSON”。所有导出新文件另存，不覆盖。旧单步和现有多步 JSON 可显式载入或导入，无自动迁移。

保存复用 SettingsPreference.WriteJson 的完整写入、Flush(true)及原子替换。沿用锁内内容 SHA 复核模式：同一 Windows 会话 Local mutex 协作，旧快照拒写；先成功持久化再改变内存、身份和保存状态。明确重新读取也保护编辑。跨 Windows 会话及不合作外部写入不承诺全局事务；不扩展服务。元数据库与重命名库文件、格式、锁及默认行为独立。

直接应用沿用脱离 UI 快照、全批来源复核、净变化统计及完整撤销。库管理不改照片草稿、不执行重命名、不保存照片。只有显式保存副本写输出，原件与旁车保护保持。固定 DateHost 和共享协议不变。
