# PhotoTrail

写真に、旅の足跡を。

PhotoTrail は無料の macOS 向け写真整理ツールです。撮影場所を補い、日時や著作権情報を整え、ファイル名をわかりやすく統一。一度読み込んだ写真で、3 つの作業をまとめて、または個別に行えます。

| やりたいこと | PhotoTrail でできること |
| --- | --- |
| 撮影場所を残す | 旅行の軌跡と照合し、地図で確認・調整 |
| 写真情報を整える | 日時の補正、作者・著作権・キーワードの追加 |
| ファイル名を統一 | 日付・場所・連番を組み合わせ、関連ファイルも一緒に処理 |

## 写真を整える 3 つの機能

### 1. 軌跡照合と地図での位置編集

**GPS のないカメラでも、旅の足跡を残せます。**

- **軌跡から位置を補う**：「＋」から時刻付きの GPX・KML・KMZ を読み込みます。サイドバーで、手順1で軌跡の記録時間内に撮影した写真を選び、手順2で不足している位置を補います。結果は一時反映され、写真を保存するまでファイルには書き込みません。
- **地図で調整**：Apple マップと高徳地図（AMap）に対応。検索、お気に入り、ピンの移動、複数写真への同じ場所の設定が可能です。
  高徳地図（AMap）は現在の表示範囲を既定で検索し、指定都市や全国にも切り替えられます。都市への移動と住所検索に対応し、地図移動後は「この範囲を検索」で更新します。写真への反映は明示的な適用時のみです。
- **写真から軌跡を作る**：位置付き写真から GPX を生成したり、位置付きコピーと確認レポートを書き出したりできます。

星形ボタンで現在の場所をお気に入りに登録し、一覧下部の幅広ボタンで残りのお気に入りを展開できます。各軌跡のチェックボックスは、その軌跡を地図に表示するかどうかを個別に切り替えます。

地域情報を補完するチェックボックスは「設定」と共通で、初期状態はオンです。既存の選択は引き継がれます。オンの場合、位置の適用時や保存時に空の地域フィールドだけを補い、既存の文字は残します。変更は一時反映され、写真の保存時に書き込まれます。

各地点に時刻のないルートは表示専用です。照合は記録の時間範囲内で行い、軌跡の切れ目をまたぎません。

### 2. メタデータの表示と編集

**撮影日時、作者、著作権をまとめて整理。**

- **ルールを保存してメイン画面から使用**：一括操作をその場で編集し、変更前後の比較は標準で折りたたみます。ルールをプリセットに保存し、メイン画面で設定を調整して読み込み済みの全写真に適用できます。「プリセットを更新」を押した場合のみ設定を保存します。
- **探して、その場で編集**：EXIF・IPTC・XMP などを名前・タグ・値で検索し、よく使う項目を直接編集。
- **定番作業はプリセットで**：撮影時刻を 1 時間進める、ファイル名から日時を復元、日付項目を統一（ファイルの作成・更新日時を含む）、作者と著作権を補完。
- **繰り返す作業をルール化**：値の設定、項目コピー、時刻補正を順に組み合わせて保存。ファイル名の日付は `YYYY`・`MM`・`DD` などで指定でき、正規表現は不要です。

JPEG、HEIC／HEIF、PNG、TIFF、WebP、AVIF、GIF、PSD／PSB、JPEG 2000（JP2）、JPEG XL、対応 RAW、既存 XMP を個別・一括編集できます。書き込める項目は形式ごとに異なり、ほかの静止画像も読み込んで情報を確認できます。[形式の対応表](../FORMATS.md)（中国語）を参照してください。

### 3. 一括リネーム

**カメラの番号を、見てわかる名前に。**

- **不足項目の扱い**：既定では不足項目を必要とするルールだけを省略し、ほかの結果を使います。名前変更設定で元の名前を保持することもできます。
- **好みの名前を組み立てる**：撮影日、場所、機器、文字、連番を組み合わせ、ドラッグで順序を変更。
- **実行前に確認**：全写真または選択した写真の旧名・新名・競合をプレビュー。
- **関連ファイルを維持**：JPG・RAW・XMP を関連付けて処理。設定を保存でき、ファイルが変わっていなければ実行記録から元の名前に戻せます。

リネーム前に写真情報を保存してください。ExFAT 対応方式も利用できます。フォルダ権限や必要容量は[詳細仕様](../BEHAVIOR.md)を参照してください。

## 変更の保存

**まず確認、書き込むのは保存時に。** 閲覧、編集、プリセット適用だけでは元ファイルは変わりません。保存前は取り消せます。

標準の「すべてのメタデータを書き込む」（⌘S）は、選択やフィルタに関係なく位置と項目の変更を一緒に保存します。設定で現在のページだけに限定できます。ローカル保存はバックアップ設定に従い、再読み取りで検証。画素を再圧縮せず、失敗した変更は保持します。

Apple「写真」ライブラリはシステム API による位置・日付の更新のみで、機能とバックアップ範囲が異なります。JPG＋RAW は位置を同期できますが、ほかの項目は自動コピーされません。

## 使い方

1. **読み込む**：写真を開くかドラッグし、撮影日時とカメラのタイムゾーンを確認。
2. **場所を補う**：サイドバーの手順で写真を選んで位置を補うか、地図で場所を選択。
3. **情報を整える**：項目を入力、またはプリセットで一括処理。
4. **保存する**：変更を確認して書き込み、必要ならリネームをプレビューして実行。

各作業は単独でも利用できます。リストからの削除は元ファイルを削除せず、コピーの書き出しも原本を上書きしません。

## 大量の写真とキャッシュ

読み込みの進捗と推定残り時間を表示し、サムネイルは必要に応じて読み込みます。設定・お気に入り・軌跡キャッシュは保持。サムネイルとメタデータ読み取りキャッシュは次回起動時に再構築します。

## 言語

簡体字中国語、English、繁體中文、日本語、한국어、Español、Português do Brasil に対応。設定で変更し、作業を保存してアプリを開き直すと反映されます。

初期設定は簡体字中国語なら AMap、それ以外は Apple マップ。手動でも選択できます。表示言語は写真の時刻を変えません。地図の言語は提供元に依存します。

## ダウンロードとインストール

[最新版](https://github.com/LittleSixNine/PhotoTrail/releases/latest) · [リリース履歴](https://github.com/LittleSixNine/PhotoTrail/releases)

**macOS 14 以降**、Apple シリコンと Intel Mac に対応。DMG を開き、PhotoTrail を終了してから「アプリケーション」へドラッグしてください。

無料で利用できます。現在の配布物は Developer ID 署名と Apple 公証が未完了のため、初回起動がブロックされる場合があります。更新の自動ダウンロードは初期状態で無効、インストールは手動です。

## AMap の利用と料金

AMap は自分の Web JS API Key と securityJsCode が必要で、macOS キーチェーンに保存されます。Apple マップには不要です。

無料枠超過や有料サービスの料金は AMap が開発者アカウントに請求します。PhotoTrail は無料で、地図の料金も徴収しません。

## 座標とプライバシー

- **写真ファイルはローカル処理**：AMap に送るのは検索語と地図関連の座標です。未キャッシュの軌跡表示や変換の更新時は、必要な軌跡座標も送信します。
- **地図と写真の座標を区別**：AMap の確定位置は検証後 WGS84 に変換。新しい選点は行政区域の検証を通過した中国本土内に限定されます。座標系不明の写真は暫定的に WGS84 として表示し、自動で書き換えません。
- **元の軌跡を保持**：地図変換は元データを変えず、時刻照合には元の WGS84 データを使います。検証は GPS や選点自体の正確さを保証しません。

## プロジェクトの由来

カメラ写真やフィルムスキャンへの位置付与から始まり、情報編集や命名へと拡張しました。一部の写真処理は [marchyman/GeoTag](https://github.com/marchyman/GeoTag) に由来します。

## Agent Skill

Mac アプリを開かずに agent で処理できます。独立した [PhotoTrail Skill](../../skill/) は、写真から GPX を生成したり、GPX で位置を補った JPEG／HEIC のコピーとレポートを作成したりします。原本は保持します。

### インストール

ローカルファイルを扱い、コマンドを実行できる agent に送ってください：

> https://raw.githubusercontent.com/LittleSixNine/PhotoTrail/phototrail/skill/INSTALL.md を読み、説明に従って PhotoTrail Skill をインストールし、実行環境を確認してください。

**Python 3.11+ と ExifTool** が必要で、macOS で検証済みです。地図検索や Apple「写真」には接続せず、RAW／XMP 書き込みは未対応。[利用ガイド](SKILL.ja.md)と[パラメータ](../../skill/SKILL.md)を参照してください。

## 開発
