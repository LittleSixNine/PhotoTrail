<h1 align="center">PhotoTrail-相跡</h1>

<p align="center">讓照片有跡可循。</p>

PhotoTrail 是一款免費的 macOS 照片整理工具。為相機照片補上拍攝地點，校正時間與作者資訊，再把零散檔名整理成清楚的順序。一次匯入，三項工作可以接著做，也可以單獨使用。

| 想做什麼 | PhotoTrail 幫你完成 |
| --- | --- |
| 找回拍攝地點 | 按旅行軌跡補定位，在地圖上檢視和調整 |
| 整理照片資訊 | 校正時間，補齊作者、版權與關鍵字 |
| 統一檔名 | 按日期、地點或編號命名，保持關聯檔案配對 |

## 三類照片整理工作

### 1. 軌跡比對與地圖定位

**相機沒有 GPS，也能留下旅行的足跡。**

- **用軌跡補定位**：點「＋」匯入帶時間的 GPX、KML 或 KMZ，在側欄依「1 選取軌跡時段內的照片、2 補齊缺失定位」操作。結果先暫存，儲存照片時才寫入。
- **在地圖上調整**：支援 Apple 地圖與高德地圖，可搜尋、收藏、拖動圖釘，或為多張照片設定同一地點。
  高德搜尋預設在目前畫面內查找，也可切換至指定城市或全國，並支援城市跳轉與地址解析；移動地圖後點擊「搜尋此區域」更新，選定結果後仍須明確套用至照片。
- **把照片連成軌跡**：從已有定位的照片產生 GPX，或匯出帶定位的照片副本與核對報告。

星形按鈕用於收藏目前位置，收藏清單底部的寬按鈕展開其餘收藏；每條軌跡的核取方塊獨立控制它在地圖上的顯示。

「補齊地區」核取方塊與設定共用一個開關，預設開啟並保留既有選擇。開啟後，套用定位及儲存時只補空白地區欄位，保留既有文字；修改先暫存，儲存照片時才寫入。

沒有逐點時間的路線僅供檢視；比對不跨軌跡斷點或超出記錄範圍。

### 2. 中繼資料檢視與編輯

**把拍攝時間、作者和版權，一次整理清楚。**

- **編排後儲存，日常直接使用**：批次編輯依動作原位展開，修改前後對照預設摺疊。規則可直接儲存為預設；主畫面改參數後套用到全部已匯入照片，只有點擊「更新預設」才儲存本次參數。
- **快速查找與編輯**：依名稱、標籤或值搜尋 EXIF、IPTC、XMP 等資訊，直接編輯常用欄位。
- **常見工作用預設**：拍攝時間加 1 小時、從檔名還原時間、統一日期欄位（含檔案建立／修改時間）、補齊作者與版權。
- **自由組合批次規則**：依序編排賦值、複製欄位與時間偏移，儲存預設重複使用。檔名日期使用 `YYYY`、`MM`、`DD` 等字元設定，不必寫正規表示式。

支援 JPEG、HEIC／HEIF、PNG、TIFF、WebP、AVIF、GIF、PSD／PSB、JPEG 2000（JP2）、JPEG XL、多種 RAW 與既有 XMP 的單張及批次編輯。各格式可寫欄位不同，更多靜態圖像可匯入檢視，詳見[格式支援](../FORMATS.md)。

### 3. 批次重新命名

**從一串相機編號，變成一眼能認出的檔名。**

- **缺欄位也能繼續**：預設略過缺少欄位的規則，保留其他結果；也可在重新命名設定中選擇遇到缺欄位時保留原名。
- **依自己的習慣命名**：組合拍攝日期、地點、設備、文字與序號，拖動調整規則順序。
- **先預覽，再執行**：核對原名、新名與衝突，可處理全部或僅選取的照片。
- **保留檔案關係**：依關聯處理 JPG、RAW 與 XMP，儲存常用方案；檔案未變更時可依執行記錄還原名稱。

改名前需先儲存照片資訊。支援 ExFAT 相容改名；目錄授權與額外空間等限制見[詳細說明](../BEHAVIOR.md)。

## 修改如何儲存

**先預覽，確認後再寫入。** 瀏覽、編輯和套用預設不會立即改動原檔；儲存前可復原。

預設「寫入所有中繼資料」（⌘S）一起儲存定位與欄位修改，不受選取或篩選限制；可在設定中改為僅儲存目前頁面。本機檔案依備份設定處理並回讀核對，不重新壓縮照片像素；失敗保留待處理修改。

Apple「照片」圖庫透過系統介面更新，僅支援定位與日期，功能及備份範圍不同於本機檔案。JPG＋RAW 配對可同步定位，其他欄位不會自動複製。

## 從一批照片開始

1. **匯入照片**：開啟或拖入檔案，核對拍攝時間與相機時區。
2. **補上地點**：依側欄步驟選取照片並補齊定位，或直接在地圖選點。
3. **完善資訊**：填寫常用欄位，或用預設批次處理。
4. **儲存修改**：核對後寫入，需要時再預覽並重新命名。

每一步都可單獨使用。從清單移除不會刪除原檔；匯出副本不會覆蓋原片。

## 大量照片與快取

匯入顯示進度及預估剩餘時間，縮圖按需載入。設定、收藏與軌跡快取會保留；縮圖與中繼資料讀取快取於下次啟動重建。

## 語言

支援簡體中文、English、繁體中文、日本語、한국어、Español 與 Português do Brasil。可在設定切換，儲存工作並重新開啟應用程式後生效。

首次設定時，簡體中文預設高德，其他語言預設 Apple 地圖，也可自行選擇。介面語言不影響照片時間；地圖語言由服務商決定。

## 下載與安裝

[下載最新正式版](https://github.com/LittleSixNine/PhotoTrail/releases/latest) · [版本記錄](https://github.com/LittleSixNine/PhotoTrail/releases)

支援 **macOS 14 以上**、Apple 晶片與 Intel Mac。開啟 DMG，結束 PhotoTrail，再將應用程式拖入「應用程式」資料夾。

軟體免費使用。目前安裝套件尚未完成 Developer ID 簽署與 Apple 公證，首次開啟可能被 macOS 阻擋。自動下載更新預設關閉，安裝需手動完成。

## 高德服務與費用

高德需自行申請 Web 端 JS API Key 與 securityJsCode，憑據保存在本機 macOS 鑰匙圈。Apple 地圖不需要高德密鑰。

超過免費額度或使用付費服務時，由高德向你的開發者帳號收費。PhotoTrail 免費，也不代收地圖服務費。

## 座標與隱私

- **照片檔案在本機處理**，不會上傳高德。高德會接收搜尋詞和地圖相關座標；主動顯示未快取軌跡或重新轉換時，也會傳送所需軌跡座標。
- **區分地圖與照片座標**：高德確認的位置經校驗後轉為 WGS84，目前僅接受行政區校驗通過的中國大陸選點。原照未宣告座標系時只暫按 WGS84 顯示，不自動改寫。
- **保留原始軌跡**：地圖轉換不改寫來源，時間比對使用原始 WGS84 資料。座標校驗不能保證 GPS 或選點本身準確。

## 專案來源

PhotoTrail 從為相機照片與底片掃描檔補定位開始，逐步擴展至照片資訊和命名。部分照片處理能力源自 [marchyman/GeoTag](https://github.com/marchyman/GeoTag)。
