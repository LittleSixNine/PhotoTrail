<h1 align="center">PhotoTrail-相跡</h1>

<p align="center">從軌跡比對、中繼資料編輯到批次重新命名，整理照片的拍攝地點、資訊與檔名。</p>

PhotoTrail-相跡 是一款 macOS 照片資訊整理工具。拍攝結束後，可依軌跡補上定位，統一照片時間、作者與設備資訊，再依規則整理檔名。三項功能共用匯入的照片，也可分別使用。部分照片處理能力源自 [GeoTag](https://github.com/marchyman/GeoTag)。

| 想整理的內容 | 使用功能 | 常見用途 |
| --- | --- | --- |
| 拍攝地點 | 軌跡比對與地圖定位 | 依旅行軌跡補定位，在地圖上檢查或調整 |
| 照片資訊 | 中繼資料檢視與編輯 | 校正時間，填寫作者、關鍵字及設備資訊 |
| 檔案名稱 | 批次重新命名 | 拍攝日期加編號、文字替換、保留附屬檔案配對 |

## 下載與安裝

[下載最新正式版](https://github.com/LittleSixNine/PhotoTrail/releases/latest) · [版本記錄](https://github.com/LittleSixNine/PhotoTrail/releases)

需要 **macOS 26 或更新版本**，安裝包同時支援 Apple 晶片與 Intel Mac。開啟 DMG，結束正在使用的 PhotoTrail，再將應用程式拖入「應用程式」檔案夾。

PhotoTrail 免費使用。目前採用臨時簽名，尚未完成 Developer ID 簽名與 Apple 公證，首次開啟可能被 macOS 攔截。自動下載更新預設關閉，安裝需手動完成。

## 三類照片整理工作

### 1. 軌跡比對與地圖定位

- **依時間比對軌跡**：匯入 GPX、KML、KMZ，以逐點時間比對照片拍攝時間。照片清單可先預覽再套用；地圖左欄可補齊缺少的定位，或明確選擇重設既有定位。只在同一軌跡區段及記錄範圍內比對，不跨斷點推算，也不默默處理多軌跡衝突。
- **在地圖上調整**：支援 Apple 地圖與高德地圖、搜尋、收藏與照片縮圖。可為多張照片設定同一位置，或拖動單張標記；高德確認的位置經校驗後轉換為 WGS84。
- **由照片建立軌跡**：將有定位與拍攝時間的照片產生為 GPX，長時間間隔自動分段。支援本機快取、顯示、隱藏及匯出，也可向新目錄匯出定位副本與核對報告。

沒有逐點時間的路線僅供檢視。軌跡 CSV 暫不支援；照片軌跡匯出為 GPX。KMZ 只讀取根目錄 doc.kml 或封存檔內唯一的 KML，不載入外部連結或附件。

### 2. 中繼資料檢視與編輯

- **常用欄位快速改**：照片資訊、拍攝時間、設備分組顯示，可直接填寫標題、說明、作者、版權和關鍵字；設備可選商品名稱或中繼資料型號，也能自訂輸入。[設備目錄與來源](../DEVICE_CATALOG.md)。
- **完整欄位清楚看**：緊湊的左右清單顯示名稱、數值和來源，支援搜尋、分組、篩選與附加標籤。背景讀取優先處理選中照片，EXIF、IPTC、XMP 與廠商私有資訊按實際來源顯示。
- **多照片、多欄位一起處理**：以 ⌘／Shift 多選，統一賦值或複製其他欄位。例如，將每張照片各自的 EXIF 建立時間複製到多個日期欄位；批次操作先預覽，再加入可復原的草稿。
- **整理與交換資訊**：支援日期偏移、相機／鏡頭及曝光資訊、預設、逐照片比較，以及受控的中繼資料 CSV／XMP 匯入匯出。

**可檢視的標籤並非都能編輯。** 新編輯器開放 JPEG 及既有 XMP 附屬檔案的 62 個 EXIF／IPTC／XMP 欄位，唯讀項目有鎖定標示。RAW 原圖、HEIC 和 Apple「照片」圖庫不開放新增欄位的編輯，原有日期／定位功能保留。中繼資料 CSV 與暫不支援的軌跡 CSV 是不同功能。[支援範圍](../BEHAVIOR.md)。

### 3. 批次重新命名

- **從常用方案開始**：拍攝日期＋編號、原名加前綴、尋找替換，也可組合文字、日期、序列、中繼資料標籤、清單和正規表示式；提供 97 個動作入口與篩選、進階設定。
- **對照原名與新名**：左側編排規則，右側核對原名、最終名稱、配對檔案及衝突。需要時檢視中間步驟，並保存預設以便重複使用。
- **保留配對與檢查衝突**：照片和附屬檔案成組預覽，不覆蓋既有檔案。當檔案身分與內容仍符合執行記錄時，可恢復原名。

可處理已匯入的本機照片，或透過「加入檔案」加入一般檔案；資料夾及照片圖庫項目不參與。如有未儲存的照片資訊或定位修改，會先提醒儲存；之後需重新核對預覽，再確認改名。重新命名獨立執行，不包含在中繼資料儲存中。

### 修改如何儲存

**「寫入所有中繼資料」**（⌘S）會寫入目前視窗中所有照片資訊與定位的待儲存修改，不限目前頁面、選取或篩選結果。瀏覽與預覽不會寫入檔案，儲存前可復原；本機寫入遵循備份設定，並回讀核對結果，不重新壓縮照片像素。JPG＋RAW 可同步保存定位，新增欄位不會自動複製至 RAW。Apple「照片」使用系統介面，編輯範圍不同。

## 從一批照片開始

1. **匯入與檢查**：完成語言、備份和地圖設定，開啟或拖入照片。先核對拍攝時間與相機時區，需要時在中繼資料頁校正。
2. **補齊位置**：匯入 GPX／KML／KMZ，選取照片、檢查比對結果並套用可靠結果。沒有軌跡時使用地圖選點、搜尋或收藏。
3. **補全資訊**：在常用欄位快速填寫，其他標籤及批次工具可切換到完整欄位使用。
4. **統一儲存**：核對修改，點選「寫入所有中繼資料」。高德需要自行配置 Web JS API Key 與 securityJsCode；Apple 地圖不需要高德金鑰。
5. **整理檔名**：選取範圍與規則，核對配對檔案、衝突及新名稱後執行。無需改名時可略過。

每項功能都可單獨使用。產生 GPX 或匯出定位副本不覆蓋原照片，從清單移除也不會刪除檔案。本機檔案備份不涵蓋照片圖庫項目。

## 語言


支持簡體中文、English、繁體中文、日本語、한국어、Español 和 Português do Brasil。首次引導先選擇語言：簡體中文預設高德地圖，其他語言預設 Apple 地圖；地圖步驟仍可手動選擇。已有用戶的地圖偏好保留。

以後可在設定中修改語言；保存工作並重新打開應用後，所有窗口及系統提示使用新語言。界面語言不改變相機時區或照片時間。地圖底圖和地點名稱的語言由地圖服務決定。

## 高德服務與費用

使用高德地圖及相關坐標轉換功能，需由你自行申請並填寫高德開發者密鑰。超出賬號免費額度或使用付費服務時，可能產生費用，由高德向你的開發者賬號計費。相關付費操作在高德開放平台完成，本軟體完全免費，不收取或代收任何費用。

高德開發者密鑰保存在本機的 macOS 鑰匙串中，不以明文寫入配置檔案，也不會上傳至本軟體開發者的服務器。調用高德服務時，密鑰僅用於向高德進行身份驗證。

## 坐標與隱私

高德會將選定位置轉換為 WGS84 後再應用；位置更改只會在手動保存後寫入照片。

- 原照片未聲明坐標系時，只暫按 WGS84 顯示，不會據此改寫原始元數據。
- 啓用高德後，搜索詞、地圖相關坐標和校驗請求會發送給高德；照片檔案不會上傳。
- 顯示尚無有效快取的軌跡時，坐標會分批發送至高德轉換；軌跡檔案本身不會上傳或修改，按時間匹配仍使用原始 WGS84 數據。
- 高德憑據保存在本機鑰匙串中；收藏與軌跡快取保存在應用私有數據目錄。
- 地圖標籤、搜索結果及地名語言由地圖服務決定；應用支持七種語言不代表底圖也支持七種語言。
- 坐標校驗可減少坐標系混用造成的錯誤，但不能保證原始 GPS 或手動選點本身的準確性。

## Agent Skill

PhotoTrail 提供可獨立安裝的 [skill 模塊](../../skill/)，無需安裝 Mac App，即可讓具備本地檔案訪問和命令執行能力的 agent 完成兩項工作：

- **照片生成 GPX**：從有定位和拍攝時間的照片生成軌跡，按時間排序並在長間隔處分段。
- **GPX 給照片補定位**：按拍攝時間匹配軌跡，支持相機時間偏移，輸出帶定位的 JPEG/HEIC 副本及處理報告，不修改原照片。

### 安裝方式

**將[安裝說明網址](https://raw.githubusercontent.com/LittleSixNine/PhotoTrail/phototrail/skill/INSTALL.md)發給 agent，讓它按照說明完成安裝。** 可以直接發送：

> 請閱讀 https://raw.githubusercontent.com/LittleSixNine/PhotoTrail/phototrail/skill/INSTALL.md ，按照說明為你當前使用的 agent 安裝 PhotoTrail skill，並檢查運行環境。

運行需要 **Python 3.11+ 和 ExifTool**，目前已在 macOS 驗證。安裝位置由 agent 客戶端決定；僅支持網頁對話、不能訪問本地檔案或運行程序的 agent 無法完成處理。照片處理在本地完成，不接入地圖搜索或蘋果 Photos 圖庫；首版不提供 RAW/XMP 寫入。

七語言安裝入口見 [Skill 使用指南](../../docs/i18n/SKILL.zh-Hans.md)，詳細參數及使用邊界見 [skill 使用說明](../../skill/SKILL.md)。skill 獨立維護，不要求與 Mac App 同步更新。

## 開發

構建需要完整 Xcode（支持 Swift 6.2、macOS 26 SDK 或更新版本）、XcodeGen 和 SwiftLint。

```sh
xcodegen generate
xcodebuild -project PhotoTrail.xcodeproj -scheme PhotoTrail \
  -configuration Debug -destination 'platform=macOS' build
```

測試、憑據配置和當前功能邊界見 [開發說明](../../docs/DEVELOPMENT.md)。

源碼位於 `Sources/PhotoTrail/`，本地 Swift 包集中在 `Packages/`，應用測試位於 `Tests/`，圖標和隱私清單位於 `Resources/`。`docs/` 保存說明與展示圖片，`scripts/` 提供構建和測試輔助命令；`skill/` 是可獨立安裝的照片與 GPX 工具。
