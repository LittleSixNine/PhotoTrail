# PhotoTrail

사진에 여행의 발자취를 남기세요.

PhotoTrail은 무료 macOS 사진 정리 도구입니다. 촬영 위치를 채우고, 시간과 저작자 정보를 바로잡고, 파일 이름을 알아보기 쉽게 정리합니다. 한 번 가져온 사진으로 세 작업을 이어서 하거나 필요한 기능만 사용할 수 있습니다.

| 하고 싶은 일 | PhotoTrail의 기능 |
| --- | --- |
| 촬영 장소 찾기 | 여행 경로와 매칭하고 지도에서 확인·조정 |
| 사진 정보 정리 | 시간 보정, 저작자·저작권·키워드 입력 |
| 파일 이름 통일 | 날짜·장소·번호 조합, 관련 파일 함께 처리 |

## 사진을 정리하는 세 가지 방법

### 1. 경로 매칭과 지도 위치 편집

**GPS 없는 카메라도 여행의 발자취를 남길 수 있습니다.**

- **경로로 위치 채우기**: ＋ 버튼으로 시간 정보가 있는 GPX·KML·KMZ를 가져옵니다. 사이드바에서 1단계로 경로의 기록 시간에 해당하는 사진을 선택하고, 2단계로 누락된 위치를 채웁니다. 결과는 임시 반영되며 사진을 저장할 때 파일에 기록됩니다.
- **지도에서 조정**: Apple 지도와 AMap에서 검색, 즐겨찾기, 핀 이동, 여러 사진에 같은 위치 설정을 지원합니다.
  AMap은 기본적으로 현재 지도 영역을 검색하며, 선택한 도시나 전국으로 전환할 수 있습니다. 도시 이동과 주소 검색을 지원하며, 지도를 이동한 뒤 “이 영역 검색”으로 결과를 갱신합니다. 사진 위치는 명시적으로 적용할 때만 변경됩니다.
- **사진으로 경로 만들기**: 위치가 있는 사진에서 GPX를 만들거나, 위치를 기록한 사진 사본과 확인 보고서를 내보냅니다.

별 모양 버튼은 현재 위치를 즐겨찾기에 추가하고, 목록 아래의 넓은 버튼은 나머지 즐겨찾기를 펼칩니다. 각 경로의 체크박스는 해당 경로를 지도에 표시할지 개별적으로 제어합니다.

지역 정보 채우기 체크박스는 설정과 같은 옵션을 사용하며, 기본값은 켜짐이고 기존 선택은 유지됩니다. 켜져 있으면 위치 적용 및 저장 시 비어 있는 지역 필드만 채우고 기존 텍스트는 보존합니다. 변경 사항은 임시 반영되며 사진 저장 시 기록됩니다.

지점별 시간이 없는 경로는 보기 전용이며, 매칭은 기록 구간과 시간 범위를 벗어나지 않습니다.

### 2. 메타데이터 보기와 편집

**촬영 시간, 저작자, 저작권을 한 번에 정리하세요.**

- **규칙은 저장하고 메인 화면에서 바로 사용:** 일괄 작업을 제자리에서 편집하며 변경 전후 비교는 기본적으로 접혀 있습니다. 규칙을 프리셋으로 저장하고 메인 화면에서 설정을 조정해 가져온 모든 사진에 적용하세요. “프리셋 업데이트”를 눌러야 설정 변경이 저장됩니다.
- **찾아서 바로 편집**: EXIF·IPTC·XMP 등을 이름, 태그, 값으로 검색하고 자주 쓰는 필드를 직접 편집합니다.
- **일상 작업은 프리셋으로**: 촬영 시간 1시간 추가, 파일 이름에서 시간 복원, 날짜 필드 통일(파일 생성·수정 시간 포함), 빈 저작자·저작권 채우기를 제공합니다.
- **반복 작업을 규칙으로**: 값 설정, 필드 복사, 시간 보정을 순서대로 구성하고 저장합니다. 파일 이름 날짜는 `YYYY`, `MM`, `DD` 등으로 지정하며 정규식이 필요 없습니다.

JPEG, HEIC/HEIF, PNG, TIFF, WebP, AVIF, GIF, PSD/PSB, JPEG 2000(JP2), JPEG XL, 지원 RAW와 기존 XMP를 개별 또는 일괄 편집합니다. 쓸 수 있는 필드는 형식마다 다르며 다른 정적 이미지도 가져와 정보를 확인할 수 있습니다. [형식 지원표](../FORMATS.md)(중국어)를 참고하세요.

### 3. 일괄 이름 변경

**카메라 번호를 알아볼 수 있는 이름으로 바꾸세요.**

- **누락된 필드 처리**: 기본적으로 해당 규칙만 건너뛰고 나머지 결과를 사용합니다. 이름 변경 설정에서 원래 이름을 유지하도록 선택할 수도 있습니다.
- **원하는 방식으로 조합**: 촬영 날짜, 장소, 장비, 글자, 순번을 넣고 드래그로 규칙 순서를 바꿉니다.
- **실행 전에 확인**: 전체 또는 선택한 사진의 기존 이름, 새 이름, 충돌을 미리 봅니다.
- **관련 파일 유지**: 연결된 JPG·RAW·XMP를 함께 처리합니다. 규칙을 저장하고 파일이 바뀌지 않았다면 실행 기록에서 원래 이름으로 복구할 수 있습니다.

이름 변경 전에 사진 수정을 저장하세요. ExFAT 호환 방식도 지원합니다. 폴더 권한과 추가 공간 조건은 [상세 설명](../BEHAVIOR.md)을 참고하세요.

## 변경 사항 저장

**먼저 확인하고, 준비되면 저장하세요.** 탐색, 편집, 프리셋 적용은 원본을 즉시 바꾸지 않습니다. 저장 전에는 실행 취소할 수 있습니다.

기본 ‘모든 메타데이터 저장’(⌘S)은 선택이나 필터와 관계없이 위치와 필드 수정을 함께 저장합니다. 설정에서 현재 페이지만 저장할 수도 있습니다. 로컬 파일은 백업 설정에 따라 처리하고 다시 읽어 검증하며, 픽셀을 재압축하지 않습니다. 실패한 수정은 보존합니다.

Apple 사진 보관함은 시스템 인터페이스로 위치와 날짜만 업데이트하며 편집·백업 범위가 다릅니다. JPG＋RAW 쌍은 위치를 동기화할 수 있지만 다른 필드는 자동 복사되지 않습니다.

## 시작하기

1. **사진 가져오기**: 파일을 열거나 드래그하고 촬영 시간과 카메라 시간대를 확인합니다.
2. **위치 채우기**: 사이드바 단계에 따라 사진을 선택하고 누락된 위치를 채우거나, 지도에서 지점을 고릅니다.
3. **정보 정리**: 자주 쓰는 필드를 입력하거나 프리셋을 적용합니다.
4. **저장하기**: 수정 내용을 확인하고 기록한 뒤, 필요하면 이름 변경을 미리 보고 실행합니다.

각 작업은 독립적으로 사용할 수 있습니다. 목록에서 제거해도 원본 파일은 삭제되지 않으며, 사본 내보내기도 원본을 덮어쓰지 않습니다.

## 많은 사진과 캐시

가져오기 진행률과 예상 남은 시간을 표시하고 썸네일은 필요할 때 불러옵니다. 설정, 즐겨찾기, 경로 캐시는 유지됩니다. 썸네일과 메타데이터 읽기 캐시는 다음 실행 때 다시 만듭니다.

## 언어

간체 중국어, English, 繁體中文, 日本語, 한국어, Español, Português do Brasil을 지원합니다. 설정에서 바꾸고 작업을 저장한 뒤 앱을 다시 열면 적용됩니다.

초기 설정에서 간체 중국어는 AMap, 다른 언어는 Apple 지도가 기본이며 직접 선택할 수 있습니다. UI 언어는 사진 시간을 바꾸지 않습니다. 지도 언어는 제공업체에 따릅니다.

## 다운로드와 설치

[최신 버전 다운로드](https://github.com/LittleSixNine/PhotoTrail/releases/latest) · [버전 기록](https://github.com/LittleSixNine/PhotoTrail/releases)

**macOS 14 이상**, Apple Silicon과 Intel Mac을 지원합니다. DMG를 열고 PhotoTrail을 종료한 뒤 응용 프로그램 폴더로 드래그하세요.

무료로 사용할 수 있습니다. 현재 배포본은 Developer ID 서명과 Apple 공증을 완료하지 않아 첫 실행이 차단될 수 있습니다. 업데이트 자동 다운로드는 기본으로 꺼져 있으며, 설치는 수동입니다.

## AMap 서비스와 요금

직접 발급한 Web JS API Key와 securityJsCode가 필요하며 macOS 키체인에 보관됩니다. Apple 지도에는 AMap 키가 필요 없습니다.

무료 한도 초과 또는 유료 서비스 요금은 AMap이 개발자 계정에 청구합니다. PhotoTrail은 무료이며 지도 요금을 대신 받지 않습니다.

## 좌표와 개인정보

- **사진 파일은 로컬에서 처리**합니다. AMap에는 검색어와 지도 관련 좌표를 보냅니다. 캐시 없는 경로를 표시하거나 변환을 새로 고치면 필요한 경로 좌표도 전송합니다.
- **지도와 사진 좌표를 구분**합니다. AMap에서 확정한 위치는 검증 후 WGS84로 변환하며 새 지점은 행정구역 검증을 통과한 중국 본토로 제한됩니다. 좌표계가 없는 사진은 임시로 WGS84로 표시할 뿐 자동 수정하지 않습니다.
- **원본 경로를 보존**합니다. 지도 변환은 원본을 바꾸지 않고 시간 매칭은 원래 WGS84 데이터를 씁니다. 검증이 GPS나 선택 지점 자체의 정확도를 보장하지는 않습니다.

## 프로젝트의 시작

카메라 사진과 필름 스캔에 위치를 넣는 도구에서 시작해 정보 편집과 이름 정리로 확장했습니다. 일부 사진 처리 기능은 [marchyman/GeoTag](https://github.com/marchyman/GeoTag)에서 비롯됐습니다.

## Agent Skill

Mac 앱 없이 agent로 사진을 처리할 수 있습니다. 독립적인 [PhotoTrail Skill](../../skill/)은 사진에서 GPX를 만들거나 GPX로 위치를 채운 JPEG/HEIC 사본과 보고서를 생성하며 원본을 보존합니다.

### 설치

로컬 파일 접근과 명령 실행이 가능한 agent에게 보내세요.

> https://raw.githubusercontent.com/LittleSixNine/PhotoTrail/phototrail/skill/INSTALL.md 를 읽고 안내에 따라 PhotoTrail Skill을 설치한 뒤 실행 환경을 확인해 주세요.

**Python 3.11+와 ExifTool**이 필요하며 macOS에서 검증했습니다. 지도 검색이나 Apple 사진 보관함에 연결하지 않으며 RAW/XMP 쓰기는 지원하지 않습니다. [사용 안내](SKILL.ko.md)와 [매개변수 설명](../../skill/SKILL.md)을 참고하세요.

## 개발

전체 Xcode(Swift 6.3+, macOS 26 SDK+), XcodeGen, SwiftLint가 필요합니다. 빌드·테스트는 [개발 안내](DEVELOPMENT.en.md), 기능 제한은 [상세 설명](../BEHAVIOR.md)을 참고하세요.

개인·업무 사용과 무료 재배포를 허용합니다. 유료 배포나 유료 소프트웨어 접근 제공에는 서면 허가가 필요합니다. [라이선스](../../LICENSE)와 [제3자 고지](../../THIRD_PARTY_NOTICES.md)를 참고하세요. Apple·AMap과 공식 관계가 없는 독립 파생 프로젝트입니다.
