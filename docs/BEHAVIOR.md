# PhotoTrail 功能与数据约定

## 设置

设置的“通用”页提供“反馈意见”按钮，打开默认邮件应用，收件人为 liujiudexiaohao@gmail.com，预填主题 PhotoTrail Feedback。正文预填运行中应用的版本号和构建号，并留出问题描述区域；用户可以编辑后自行发送。不自动附加照片、轨迹、日志或设备信息；页面也显示可复制的邮箱地址。

设置窗口按通用、地图、照片与保存、轨迹、存储分组。默认显示全部照片标记；关闭“在地图上显示所有照片的位置”后，仅显示选中照片的位置。默认允许双击地图和拖动照片标记定位，地区名称自动查询。地图启动视野默认尝试设备位置，定位不可用时回退该地图来源的上次视野，没有记录时使用原预设位置；也可选择直接恢复上次视野。主界面的地图来源、标准／卫星和高德凭据入口与设置共用偏好及钥匙串记录。关闭地区名称自动查询不会关闭地图搜索、图块或高德选点校验。

“保存前显示修改摘要”默认关闭。开启后，工具栏保存和 ⌘S 均在写入前列出本地照片、XMP、照片图库的实际待保存件数及备份状态；取消不会开始保存或清除撤销记录。

对原有日期／定位保存路径，启用“创建 XMP 附属文件”后，没有同名 XMP 的本地照片会先创建附属文件，本次修改写入新 XMP，原图元数据不改。若保存期间已经创建 XMP 但后续步骤失败，界面仍按实际文件来源切换到 XMP，并保留未保存状态供重试；创建流程不会覆盖保存期间新出现的同名 XMP。

对原有日期／定位保存路径，启用“给更新的文件添加 Finder 标签”后，标签写入作为元数据保存后的独立步骤。若元数据已成功写入而仅 Finder 标签失败，照片仍标记为已保存，并提示标签未添加；其他文件的元数据写入失败仍保留待保存状态。

新会话默认使用系统相机时区；指定时区只影响随后新建的会话，当前批次仍可单独调整。从照片创建 GPX 的断段默认间隔为 5 分钟，两个创建入口都允许本次临时调整。JPG／RAW 同名配对及递归导入默认开启；配对开关仅作用于后续导入，已导入照片的分组保持不变。备份清理默认仅提醒超过 7 天的旧备份，可改为 30、90 天或不提醒，删除仍须确认。

文件选择、拖入和文件夹导入共用同一导入筛选：照片列表只接收系统识别为图片的文件；混合导入会跳过其他文件并提示数量，GPX 仍按轨迹导入。旧版本已进入列表的不可编辑条目可在文件名上打开菜单，直接从列表移除；移除不删除原文件。

## 高德点选

1. 首次启动依次完成语言、备份、地图、确认四步引导；简体中文默认高德，其余六种语言默认 Apple 地图，仍可手动选择。打开测试照片副本。
2. 在地图设置菜单的“高德 API 设置”中填写自己的 Web 端 JS API Key 和 securityJsCode，保存到本机专用钥匙串记录。
3. 选中可编辑照片，在地图点选位置。程序先查询行政区，再将 GCJ-02 本地转换为 WGS84；调用一次高德官方正向转换检查，回到点击点的误差须不大于 5 米。
4. 检查提示后保存，关闭并重新打开副本验证。新位置标记 GPSMapDatum=WGS-84、GPSProcessingMethod=MANUAL。

高德凭据只保存在钥匙串；应用使用内存中的凭据填充设置界面，避免重复读取。若启动时拒绝钥匙串访问，可在高德设置中点“从钥匙串读取”再次请求并填充凭据。临时签名版本重新构建后仍可能触发系统授权。未配置密钥时不创建高德网页，地图区域显示完整的设置说明。

启用高德后，显示照片和校验选点会发送经纬度到高德；照片文件不会上传。
安全密钥会进入地图 JavaScript 运行环境；钥匙串仅保护本机存储。本原型采用官方文档中的开发方式，公开服务需要另行配置安全代理。

关闭主窗口或退出应用时，如有未保存修改，应弹出“有未保存的修改”，提供“继续编辑”和“放弃修改并退出”；默认继续编辑，不丢弃修改。保存正在进行时继续拦截退出。

## 数据约定与范围

- 高德经纬度仅用于地图交互；高德确认的新位置写入照片前转换为 WGS84。
- 原照片未声明 GPSMapDatum 时，只暂按 WGS84 显示，不据此修改或补标原始坐标系。明确声明其他基准的照片不显示原标记。
- 仅修改日期或地址时，保留 GPS；用户显式开启原版“更新 GPS 时间戳”选项时仍按该设置更新 GPS 时间。
- 本原型仅允许高德行政区代码确认为中国大陆的选点，未知、境外及港澳台点暂不写入。公式的数值边界不是国界判断。
- 苹果与高德默认显示全部有有效定位的导入照片，也可只显示选中照片；缩略图由原生层显示，不进入高德 JavaScript。拖动只更新稳定 ID 对应的单张照片，仍需手动保存。
- 本地逆转换是近似算法。往返误差测试验证计算一致性，不能证明实际拍摄位置精度。每次官方正向复核也不替代真实地点验收。
- Photos 图库通过苹果接口更新位置，不能自行设置图库导出照片的 EXIF 基准标签；需另行验证导出行为。

## 验收要求

先用公开地点和生成图片完成点选→保存→重开，再用私人目录的照片副本验收。
至少验证 JPEG、HEIC、RAW+XMP，以及取消保存、断网、快速切换照片、连续点选。
真实服务测试需要有效凭据；未提供凭据时，仅运行公式、元数据和地图交互的离线测试，不把模拟测试写成实测通过。
私人照片、真实拍摄位置、凭据和构建日志不提交到代码仓库。

## 搜索与收藏

详情页左侧显示经纬度、收藏地点和 GPX 轨迹工具；地图来源和高德 API 凭据入口位于地图设置菜单。
苹果与高德共用地图左下角搜索浮层，结果分为地点名和地区两行；选择结果仅预览，点击“应用到照片”才修改位置。
地图设置菜单及设置窗口的“高德地图配色”提供全部 11 种官方配色，界面外观提供亮色、暗色和跟随系统（默认），设置窗口与地图设置菜单共用选择。亮色地图默认月光银，暗色默认幻影黑，两套搭配独立保存；跟随系统时按实际外观读取，重载及重启后恢复。旧版手动选择的配色保留为亮色搭配，卫星视图返回标准视图后继续使用所选配色。地图左上角可切换标准/卫星视图。地图启动默认请求一次系统定位以确定初始视野；右下角定位按钮可再次请求定位并移动地图。两者均不修改照片。
左栏默认宽度为窗口的 26%，照片条默认高度为 13%；拖动尺寸会保存在本机。地图左栏固定保留垂直滚动条槽位，滚动条仍沿用闲置淡出样式，避免临界窗口高度下显示／隐藏滚动条改变预览宽高并反复重排。
高德搜索使用官方 JS API 的 AMap.PlaceSearch，输入后显示候选地点；选中候选只预览，点击“应用”才修改选中照片的位置，仍需手动保存。
收藏支持名称、备注、编辑和删除，保存为 WGS84，存放在应用私有 `Application Support/PhotoTrail/Favorites.json`，独立于公开代码。首次启动会复制旧 `GeoTagCN` 文件，原文件保留。点击收藏名称预览，点击“应用”设置选中照片的位置。
高德标记使用内嵌 SVG，不依赖默认图标的外部资源加载。应用菜单、主要窗口、设置及提示已加入简体中文。

单元测试方案设置 `PHOTOTRAIL_OFFLINE_TESTS=1`，不加载私人收藏、凭据或交互窗口。独立测试 bundle 标识避免打断日常应用；单元测试不等于真实界面或在线接口验收。

## 双页面界面

顶部“照片列表／地图定位”共用选择及未保存状态。照片列表负责整批筛选、批量操作和匹配结果复核；地图定位负责照片预览、地点搜索及纠偏。双击列表照片进入地图定位，返回时保留照片状态筛选、排序和选择。

列表显示保存状态、缩略图、文件名、时间、合并的定位列（上纬度、下经度）和上次轨迹匹配结果；绿色圈勾仅表示无未保存修改，缺少坐标也可以显示绿色。批量操作侧栏由工具条按钮展开或收起，面板宽 200 点，操作按钮统一填满可用宽度，采用相同控件底色和 1 点描边，图标固定 16 点宽、图文间距 7 点并左对齐；“保存所有修改”和“撤销”固定在面板右下方，其他操作独立滚动。轨迹匹配设置按需展开，先预览再应用。上次匹配结果用于复核，不代表手动编辑后的当前定位；可筛选未成功的结果或清除记录。匹配结果保存在当前窗口会话中，重启后不恢复。

照片状态筛选使用紧凑菜单，避免常驻元数据分栏挤压按钮；各选项仍显示数量。常规照片状态与文件名筛选会移除不可见照片的选择。匹配结果筛选保留选择用于复核，工具条同时显示选择总数与当前可见选择数，批量操作仍作用于全部选择。

顶部主工作区为“元数据编辑”“地图定位”“重命名”；元数据编辑沿用照片列表，重命名采用原生双栏，左侧编辑顺序规则，右侧核对原名、中间步骤、最终名称与状态；切换不丢失当前照片、草稿与规则。列表页右侧元数据面板常驻，可拖动分隔线调宽，取消原 640 点宽度上限，保留照片列表最小宽度，无需点击“照片信息”。右栏顶部固定显示选择范围、读取来源、保存按钮与待保存状态；搜索及筛选、分组、显示设置固定在其下，日期／预设／交换与重新读取收进更多菜单。滚动内容使用原生分组列表，组名与字段行分开；字段名称用 15 点、组名用 16 点半粗体，规范标签用 10 点和第三级颜色；字段值改为 17 点（较原 callout 增加两档），值与箭头／锁在行内垂直居中。日期和时间的完整字段以 `YYYY-MM-DD HH:mm:ss` 和完整等宽字体显示，右侧箭头／锁统一占 16 点宽以对齐时间右边缘；有时区时统一换算到本机时区，下行列出实际 UTC 偏移，小数秒明确标为“亚秒 0.26 秒”等，保留原精度。无时区保留原墙上时间并标明“时区未记录”，仅日期／仅时间单独标记，不虚构缺失组件；无法解析或包含多个来源的值保留读数。显示格式不改变保存值和复制原值。光圈显示为 `f / 数值`，曝光时间及快门速度显示为分数秒或秒数；不足一秒且距常见快门档位不超过 3% 时用该档位显示，超过浮点误差的近似带 `≈` 标识，否则保留计算所得分母。ExifTool 读取的 ShutterSpeedValue 已按 ValueConv 转为秒，不再次按 APEX 换算。只改变显示，不改变存储值及复制原值。可编辑行有轻量箭头，只读行有锁标识。左侧照片列表保留状态、预览、文件名，删除拍摄时间、定位和已匹配轨迹三列，增加“原标签”和“已编辑”；仍可按拍摄时间排序与筛选匹配结果。默认显示 11 个分组的 73 个 MetaImage 参考字段，并补充独立的 XMP 编辑字段；空字段保留。可按本地化名称、规范标签或值搜索、跳转分组、筛选有值／待保存字段，以及管理显示字段并恢复默认；显示偏好本地保存。“显示所有附加字段”可查阅原文件的其他已读标签。EXIF、IPTC、XMP 同义来源分别显示，多个命名空间或 IFD 明确列出；已有 XMP 的图像字段从原图读取，XMP 字段从实际 sidecar 读取。

写入白名单为 62 个规范标签：19 个 XMP、31 个 EXIF（含 3 个日期精度组合标签）和 12 个 IPTC。每行标出实际写入标签；不自动同步同义来源。字段行单击高亮，⌘ 点击逐项增减选择，Shift 点击连续选择，也可用 Shift＋方向键扩展；字段选择与照片选择相互独立，切换照片或筛选／显示字段时清空字段选择。双击可编辑行或点击右侧箭头打开类型编辑器；右键按字段类型提供编辑、粘贴、仅补空值、关键词追加／移除、日期偏移及清除，均进入已有编辑器后预览，不直接写磁盘；规范原值与含单位的显示值分别复制，列表原值按逐行格式复制，多选混合值或空值不复制汇总占位文字。可复制规范标签；只读行只提供复制显示值和标签。字段编辑窗口为 620 点宽，普通字段 480 点高，日期字段 640 点高；内容可滚动，预览／取消／加入草稿按钮固定在底部。只读字段可选中并通过右键复制，禁用字段不进入编辑器。字段列表取得键盘焦点时，⌘A 只全选字段，照片定位的剪切／复制／粘贴／删除快捷键停用，避免误操作照片；字段操作使用右键或批量菜单。文字／列表、日期、数值／枚举使用相应编辑入口，可复制、粘贴、恢复原值或清除，修改仍须先预览，再加入可撤销草稿。标题、说明、版权的 XMP 只修改 `x-default`，其他语言保留；作者和关键词列表每行一项，关键词按 UTF-8 字节精确去重，保留大小写和不同 Unicode 拼写。

IPTC 新建时写入 UTF-8 声明；已有 IPTC 仅在明确声明 UTF-8 时开放设置，不猜测旧编码、不隐式转换整组标签。编码不明确时预览／写入拒绝设置，原文件保持。显式清除不需要重编码。

选中字段后，“批量操作”及所选行右键提供复制其他字段的值、统一赋值、粘贴和清除。窗口列出实际可写目标及被排除的只读字段数；类型不兼容或非法日期在预览时拒绝。复制对每张照片分别取来源字段的当前有效值（包含待保存草稿），来源缺失则跳过并保留目标原值；全日期目标只列日期来源，JPEG 默认来源为 EXIF CreateDate 的精度组合标签。EXIF 日期以 Composite 标签成组保留主时间、亚秒及 UTC 偏移，XMP 日期保留原精度，无时区值不补造时区。多字段操作仍先预览，再一次加入可撤销草稿，最后手动保存；剪贴板粘贴则将同一个字面值应用于所选照片和字段。混入只读字段不扩大写入白名单。

新编辑器开放 JPEG 图内字段与已存在的 XMP sidecar；RAW 原图、HEIC 与 Photos 图库的新字段入口禁用，原有日期／定位功能保留。JPEG+RAW 不自动传播新字段。预览冻结选中条目、列表排序、实际目标与文件版本；同一物理文件的重复目标拒绝写入。先加入可撤销草稿，再手动“保存所有修改”。同一文件多个新字段合并为一次备份和写入；有旧日期／定位草稿时先完成或放弃那一组。保存前重新检查来源，按实际目标备份，只写改动的标签并回读；失败保留草稿，结果未知须核对磁盘并放弃后重新建立草稿，不能盲重试。批量保存可在当前文件完成后取消，后续草稿保留。浏览、预览、切换地图均不自动保存。

“日期、预设与交换”复用该保存链路。JPEG 的 EXIF 拍摄时间同时管理 DateTimeOriginal、SubSecTimeOriginal、OffsetTimeOriginal；已有 sidecar 的列表时间目标为 XMP-xmp:CreateDate。这两个主日期草稿投影到既有列表／地图／GPX 时间模型；清除主日期后缺少匹配时间，保存并重开仍一致。EXIF 数字化／修改日期及其他 XMP 拍摄、数字化、修改日期是独立字段，不暗中覆盖主时间。逐日期字段编辑器增加“时间偏移”卡片，年／月／日／时／分／秒分别输入有符号整数，按此顺序对每张照片的当前值（含草稿）计算；保留亚秒及明确偏移，缺失日期不自动补值，年／月导致无效日期时拒绝预览、不自动收敛到月末。设定、秒偏移、日历天、指定组件、起点＋步长、区间均分均预览后应用；无时区保留墙上时间，有明确偏移优先使用该偏移，亚秒保留；无效闰日／月末、DST 不存在时刻、缺失源时间和倒序区间拒绝。序列按冻结排序；均分四舍五入至整秒并保留端点及原亚秒，单张取起点。文件名正则解析用捕获组与日期模板生成候选值，匹配失败或非法日期逐项列入跳过清单，不回退当前时间。JPEG 主时间明确读取 EXIF，避免 ImageIO 从旧 XMP 同义字段回退而让已清除时间重新出现。相机厂商／型号、机身序号、镜头厂商／型号／序号可分别编辑指定 EXIF 或 XMP 标签；胶片信息可放说明或关键词。

数值白名单包括 XMP 与 EXIF 曝光时间（秒，可输入 1/125）、光圈、ISO、焦距、曝光补偿；EXIF 另有快门速度、光圈／最大光圈和 35mm 等效焦距。界面显示单位、范围；EXIF ISO 与等效焦距受 16 位整数约束。曝光程序、白平衡、曝光模式、测光模式、色彩空间、饱和度和锐度只允许所列合法值；闪光为 0–127 的 EXIF 位标志。回读数值按精度核对，EXIF APEX 有理数换算容差为百万分之一，其余十亿分之一。文件路径／时间、尺寸、GPS 成组字段、IPTC 独立日期／时间和厂商私有字段当前只读，不加入新编辑器。

命名预设为版本 1 的有序 JSON 动作；固定设置、仅补空、清除、文字追加、关键词、日期与按字段复制共享预览。后一步读前一步结果；复制源缺失跳过并提示；未知版本／标签／动作拒绝。固定设置／精确关键词追加重复应用可无变化；文字追加与日期偏移会再次生效，预览展示最终值。

比较表显示前 20 张，CSV 操作作用于全部冻结选择。可回写 CSV 使用版本标识、基于已授权目标路径的稳定 ID 和相对路径双重校验：文字／列表是 JSON 值，空格不冒充空值，空单元格保持，`@clear` 显式删除；未知列、无匹配行、非法单元格提示跳过，重复身份与越界路径拒绝。安全显示 CSV 对公式前缀加引号且不可导回。XMP 导出为磁盘中的元数据快照（未保存草稿不包含）；导入只合并已开放且存在的 XMP 字段，缺失保持，预览冲突，不直接替换文件。导出不允许覆盖当前选中的原图或 sidecar。

检查器显示逐文件结果，可单独放弃草稿。打开期间前台约每五秒及回到应用时检查外部文件版本，有变化重新读取；读取失败单独提示，不能当成缺失值。地图页布局及原有位置保存路径保持原样。

右键菜单以右键目标集为操作范围；右键未选中照片不把原有选择混入操作。复制定位仅支持单张来源，粘贴和匹配明确显示目标数量。移除照片只改列表，配对 JPG＋RAW 一起移除，原文件不删除、不修改；确认提示明确未保存修改会移出当前列表，可撤销恢复。清除定位保留照片，仅清除坐标与相关地点信息，配对文件同步修改，保存后才写入文件。保存期间禁止移除及修改定位。菜单不再使用无范围的“剪切”“删除”。

回到当前使用准星图标，只将主选照片滚动到照片条中央，不修改选择、地图视野或照片定位。筛选仅影响照片条；被隐藏的当前照片仍保留选择与预览，回到当前置灰并提示原因。底栏最小高度为 132 点，缩略图大小继续由底栏拖动高度决定。

## 地图与表格实现

搜索控件在同一胶囊中切换材质：收起用 `Glass.clear`，展开输入时用 `Glass.regular`，保持 44 点高度及原来的动画和减少动态效果支持。结果列表使用 `regularMaterial` 标准磨砂，跟随应用亮暗外观以保证阅读。

高德地图画布通过 `.ignoresSafeArea(.container, edges: .top)` 延伸到浮动标题栏下，不再使用会复制边缘的 `backgroundExtensionEffect()`。`AMapWebView` 使用公开的 `obscuredContentInsets` 显式将网页遮挡边距归零（先赋不同值，避开 WebKit 的相等值短路），避免 WebKit 再为标题栏留出空白；搜索、图层切换和导航按钮仍由原有 SwiftUI 布局定位。

列宽拖动改为真实表头上的窄拖动区域，避免依赖全窗口鼠标监视器。移动分隔只调整左右两列；分隔获得焦点后可用方向键调节。测试覆盖表头命中、鼠标事件路径、相邻宽度总和、最小宽度和后续列保持不变。

### 左栏 GPX 轨迹与转换缓存

界面范围仅为详情页左栏：照片预览、当前位置、收藏与轨迹统一纵向滚动，无切换页签。每个 GPX 文件一行：复选框控制显隐，点击行选中并自动查看范围，右上角按钮重新读取该文件并刷新。轮廓由本地 WGS84 坐标按比例绘制，保留断点；记录时间来自有效 GPX 时间戳，按本机时区显示，跨天包含日期，无时间明确标注。状态、进度、取消和重试均在对应行内。

`GpxTrackLog.sourceURL` 绑定文件身份，重复导入替换同一条记录而不增加重复项。照片匹配仍使用原始 WGS84、时间与海拔，与显示勾选和高德缓存无关。从操作区移除不删除源文件、历史记录或转换缓存；菜单里的缓存清除仅清除转换结果。

`TrackLibrary` 在应用沙盒 `Application Support/PhotoTrail/Tracks/cache-v1.json` 原子保存版本化清单、只读安全书签、原始轨迹和高德 GCJ-02 结果；首次启动复制旧 `GeoTagCN` 缓存且不删除原件。目录 0700、文件 0600，不保存凭据。每个窗口首次只恢复历史记录，不自动加入本次操作区；读取一次缓存和可访问源文件，后续显隐使用内存。按坐标顺序和分段内容计算稳定 SHA-256 标识；源文件变化或无效结果不沿用旧缓存，损坏的缓存文件保留、不用空文件覆盖。原文件失联时保留缓存用于查看，但不恢复进照片时间匹配。历史恢复不触发高德转换；点击“加入”后才显示并参与本次操作。

GPX 卡片按标题、历史记录、本次轨迹、照片匹配操作排列。历史记录默认收起，展开显示轨迹轮廓、文件名、记录时间、缓存状态与“加入”按钮；已在操作区的记录不能重复加入。三个匹配按钮纵向等宽排列，保留补齐与覆盖的说明。导入后的结果弹窗取消，失败文件在卡片中提示，照片列表页提供查看入口。文件选择器保留。

新导入轨迹自动显示；使用高德时按本次列表顺序排队转换，一次只提交一个文件。等待、进度、取消和失败重试显示在对应行；失败或取消后继续下一条。苹果地图使用原始坐标无需转换，切换高德后自动排队处理可见且没有有效缓存的轨迹。历史轨迹加入时检查源文件；有效缓存直接复用，源轨迹变化才重新转换。原文件不可用时仅预览缓存，不加入照片时间匹配。

每条轨迹独立转换与显示，所有文件共用一个 JS 队列：每批最多 40 点，请求起始间隔至少 1.1 秒，QPS 限流最多延迟重试两次。单文件完整转换后保存并替换旧结果。刷新失败／取消保留旧轨迹，旧任务结果不能覆盖新请求。样式、选中范围及显隐不重新转换；重新加载地图直接重新绘制内存结果。错误提示只含固定文案和筛选后的服务错误码。


官方接口依据：[坐标转换及 40 点上限](https://lbs.amap.com/api/javascript-api-v2/guide/transform/convertfrom)、[Polyline](https://lbs.amap.com/api/javascript-api-v2/guide/amap-line/poly-line)。

地区查询实现：显式 completion + continuation 接收 WKWebView 异步返回值，避免 Void 重载丢失结果。

### 滚动条

照片列表、详情侧栏、照片条、批量操作、搜索结果、设置、首次引导和日志使用较细的 5 点圆角滑块。保留原生滚动、拖动和命中区域；滑块颜色随亮暗外观变化，增强对比度时提高可见性。停止滚动 3 秒后以 0.3 秒渐隐，重新滚动或鼠标进入滚动条区域时恢复；悬停及拖动期间不隐藏。启用减少动态效果时直接隐藏，不播放渐隐动画。应用内滚动条使用独立的隐藏计时，不修改 macOS 全局偏好。

## 元数据右栏读取与刷新

导入沿用基础元数据读取；列表出现后，每个窗口用单一后台队列补齐本地图片的 62 个可编辑白名单标签、兼容作者及所有可识别家族的展示读数（含 EXIF、IPTC、XMP、MakerNotes、ICC、Photoshop、容器与派生字段）。已有 XMP 同时读取原图的非 XMP 展示标签。同名标签采用 family-1 来源与 family-4 副本标识保留，不让 JSON 同名键覆盖；原始二进制内容仅显示引擎的摘要，不导出图片负载。选中图片的可编辑快照优先，其完整展示读数其次，其他等待任务排后；已开始的读取安全完成，不强杀进程。核心快照可先显示，只读目录未完成时标为“正在读取”，失败与未填写区分。缓存命中的选择立即呈现；未命中时有 100／150 毫秒短暂合并窗口，取消选择任务不会取消其他图片的后台预读。“显示所有附加字段”只控制呈现，不再触发另一轮完整读取。

窗口保留当前导入集合的读取缓存，移除图片时回收；按实际 URL、原图 URL、读取类型及两份文件版本核对，重复选择未变化的文件复用缓存。共享的跨视图缓存仍最多 64 份数据集。保存后及右栏 5 秒检查仍核对版本；手动重新读取清除相关 URL 的缓存，并重新入队。读取过程中来源改变则丢弃旧结果并重排，失败可通过重新读取重试。预览和保存继续独立检查冻结目标与磁盘版本，缓存不会绕过这些检查。缓存只在会话中保留，重开窗口重新读取。

工作区进度显示已读取、总数及失败数；列表“原标签”旁显示等待、读取或失败状态，尚未完成不显示虚构的零。“原标签”统计已读取的原始元数据标签（含厂商私有、色彩及容器信息），排除 File／System 文件属性、Composite 派生字段及 ExifTool 引擎信息；命名空间／IFD 与同源副本分开，关键词数组计一个标签。它表示信息量，不是完整率。计数反映最近的磁盘快照，保存后重读更新；“已编辑”为当前尚未保存的字段数，包含新元数据草稿与旧日期／地图定位草稿。Photos 图库项目不参加本地文件完整预读计数。

## 文件重命名（源码开发版）

第三个标签页可使用已导入的本地照片，或通过“添加文件”加入普通文件；照片图库项目、目录和符号链接不参与。元数据草稿必须先保存或放弃，写入期间不能执行改名。添加文件后通过原生目录选择器授权所在目录，用于扫描配对、检查重名和安全改名；已由照片导入授予的目录权限会复用，未授权时不扫描目录并阻止执行。只处理预览中的文件，不递归遍历。规则可启停、排序、复制，提供文字、字符、大小写、兼容名称、日期、数字／罗马数字／字母序列、音乐／照片标签、尺寸、父目录／路径、文件列表及正则表达式等 97 个动作入口；另有分段筛选和高级设置。动作入口不代表全部第三方参数已完全复刻。

名称可针对主体、完整名称、带点或不带点的扩展名处理；字符位置从零计，按 Unicode 字形簇计数。拍摄时间按可编辑来源优先级读取，存在偏移才换算时区，未记录时区保留墙上时间；可设置夜间归入前一日期。缺少日期／模板字段默认整组保持原名。数字序列提供手动值与十个持续计数器，预览不消耗计数，全部执行成功后才推进；执行前核对计数是否变化。后续规则因缺字段跳过某一组时可能留下编号空隙，下一批从已分配的最高序位之后继续，不复用后面已分配的编号；每目录编号按本批最高序位推进。同一持续计数器不能在一个方案中重复使用。

默认扫描同目录同主体的照片及旁车，全部列入预览；主文件产生主体，其他成员保留各自扩展名，最终冲突后缀整组一致。可关闭配对；已加载 XMP 来源的照片必须保持照片与旁车实际配对，否则阻止执行。冲突可阻止执行或添加数字／字母后缀，不覆盖已有文件。执行前重新检查源身份，暂存全部变化源后再提交目标，支持交换及循环改名，并回读 SHA-256 确认内容。文件操作采用不覆盖的原生改名接口，不能保证断电时跨多个文件的事务原子性。

成功后保持照片 ID、选择与配对关系，更新名称、元数据来源和撤销基线，清空旧路径编辑撤销记录及读取缓存，后续保存使用新路径。执行记录持久保存原名、目标、暂存位置、身份、内容哈希与可获取的安全作用域书签，可在“执行记录与恢复”恢复原名；文件内容后来被编辑或原名被占用时拒绝恢复。中断时先尝试恢复，失败保留记录；当前窗口涉及未恢复文件的照片禁止继续元数据写入。恢复失败或外部移动后应核对实际路径，不自动猜测。

预设为 PhotoTrail 自有版本 1 JSON，可保存、导入、导出；不支持直接导入第三方程序的预设、Droplet 或 Finder 扩展。模板使用 `<标签>`，提供候选与已读实际标签；候选存在不代表当前格式能提供读数。模板可能包含文件名非法字符，须核对状态。正则替换支持捕获组和 `\U/\L/\u/\l/\E` 大小写转换，重排可选择整段匹配。仅提供一个任务级排序键。兼容名称动作未经 Mac OS 9、DOS 或外部 NTFS 卷验收。

## 设备目录与加载优化（源码开发版）

EXIF 的 IFD0:Make／Model、XMP 的 tiff:Make／Model 编辑器提供品牌、机型搜索与已核实值选择，仍保留自定义文本。选择只填当前字段，不连带改写其他来源或厂商私有信息；统一值、预览、草稿、备份、保存和回读仍走原路径。当前范围、证据和未覆盖情形见[设备目录](DEVICE_CATALOG.md)。

元数据面板每轮构建复用一次所选照片的合并值和编辑资格，搜索无须读取值时跳过值投影；完整多选汇总仍等待该批数据齐全。快速切换照片时，取消的预览任务不更新画面，缓存按原始照片 ID 回填，已移除照片的结果被忽略。导入后后台预读、选中插队、缩略图按需加载、地图可见范围限量与重命名预览防抖继续保留。


## 元数据编辑器与右栏（源码开发版）

单字段与批量编辑窗口采用 880 × 660 的 4:3 布局，左侧编辑、右侧当前内容／逐照片修改预览、底部固定操作。62 个白名单字段分别使用单行文本、多行描述、作者／列表、日期与六项偏移、数值／分数、枚举、闪光状态、品牌／型号控件。数值显示单位与范围，IPTC 显示字节限制，国家代码显示三字母说明。枚举保留已有未知值的显示；闪光灯提供常用状态，也允许原始代码。时间文本保留秒、亚秒和偏移，日期控件继续复用原有精度与时区路径。

设备选择不再使用独立的名称切换开关：在型号菜单中直接点击商品名或元数据型号；同一行对应同一设备，相同值合并显示。仅有官方商品名证据的选项标为“仅商品名”，不提供未核实的元数据值，也不作为制造商候选。最终输入框始终可手动修改；选择品牌时，制造商编辑器填入该品牌已核实的 Make，型号编辑器只改变筛选范围。

右栏按字段名、值、技术标签分层；铅笔提供编辑入口，待保存与只读均有文字和图标，顶部给出“选择字段 → 编辑并预览 → 保存照片”的顺序。单击选择、⌘ / Shift 多选、双击编辑、搜索筛选和右键批量操作继续使用原生列表与既有路径。只读字段不因界面重设计获得写入权限。加入待保存不会立即改写文件，保存、备份、版本检查和回读保持原有边界。
