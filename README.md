<h1 align="center">PhotoTrail-相迹</h1>

<p align="center">让照片有迹可循。</p>

PhotoTrail 是一款免费的 macOS 照片整理工具。为相机照片补上拍摄地点，校正时间与作者信息，再把零散文件名整理成清晰的顺序。一次导入，三项工作可以连着做，也可以单独使用。

**定位、信息、文件名，一批照片一起整理。** 可以整批处理，也可以只选需要的照片；常用的编辑与命名规则，还能保存下来重复使用。



| 想做什么 | PhotoTrail 工作流 |
| --- | --- |
| 找回拍摄地点 | 按旅行轨迹补定位，在地图上查看和调整 |
| 整理照片信息 | 批量校正时间，补齐作者、版权与关键词 |
| 统一文件名 | 按日期、地点或编号批量命名，保持关联文件配对 |

## 三类照片整理任务

### 1. 轨迹匹配与地图定位

**相机没有 GPS，也能留下旅行的足迹。**

- **用轨迹补定位**：点“＋”导入带时间的 GPX、KML 或 KMZ，侧栏按“1 选择轨迹时段内的照片、2 补齐缺失定位”的顺序操作。结果先暂存，保存照片时才写入。
- **在地图上调整**：支持 Apple 地图与高德地图，可搜索、收藏、拖动图钉，或批量设置地点。高德支持中国大陆定位转换，将地图选点转换为照片使用的 WGS84 坐标；需自行申请并填写高德 API 凭据。
  高德搜索默认在当前画面内查找，也可切换到指定城市或全国；支持城市跳转和地址解析，移动地图后点击“搜索此区域”刷新，选定结果后仍须明确应用到照片。
- **把照片连成轨迹**：从已有定位的照片生成 GPX，也可导出带定位的照片副本与核对报告。

星形按钮用于收藏当前位置，收藏列表底部的宽按钮展开其余收藏；每条轨迹的复选框独立控制它在地图上的显示。

“补齐地区”复选框与设置共用一个开关，默认开启并保留已有选择。开启后，应用定位及保存时只补空白地区字段，保留已有文字；修改先暂存，保存照片时才写入。

例如：一趟旅行拍了几百张照片，导入轨迹就能按拍摄时间补上地点；同一地点的照片，也可以选中后一并设置。

### 2. 元数据查看与编辑

**从统一校时到补全信息，一次处理多项修改。**

- **编排后保存，日常直接使用**：批量编辑按动作原位展开，修改前后对照默认折叠。规则可直接保存为预设；主界面改参数后应用到全部已导入照片，只有点击“更新预设”才保存本次参数。
- **查看与批量填写**：按名称、标签或值搜索 EXIF、IPTC、XMP 等信息，直接编辑常用字段，也能为一批照片统一填写作者、版权、关键词和设备信息。
- **灵活安排拍摄时间**：整体偏移、修改指定日期部分、按固定间隔逐张设置，或在起止时间内均匀分配。还能从文件名恢复日期，用 `YYYY`、`MM`、`DD` 等字符配置格式，无须编写正则。
- **组合规则，重复使用**：赋值、复制字段和时间调整可按顺序组合，保存为预设下次使用。内置加 1 小时、从文件名恢复时间、统一日期字段（含文件创建／修改时间）、补齐作者与版权四项预设，可直接调整。

例如：一批胶片扫描照片没有拍摄时间，可以先从文件名恢复日期，再按每张间隔 1 分钟安排时间，最后统一补上作者与版权。

支持 JPEG、HEIC／HEIF、PNG、TIFF、WebP、AVIF、GIF、PSD／PSB、JPEG 2000（JP2）、JPEG XL 及多种 RAW 的单张与批量元数据编辑，也可编辑已有 XMP。各格式可写字段不同，更多静态图像可导入查看，详见[格式支持](docs/FORMATS.md)。

### 3. 批量重命名

**从一串相机编号，变成一眼能认出的文件名。**

- **缺字段也能继续**：默认跳过缺少字段的规则，保留其余结果；也可在重命名设置中选择遇到缺字段时保留原名。
- **按你的习惯命名**：组合拍摄日期、地点、设备、文字和序号，拖动调整规则顺序。
- **先预览，再执行**：同时核对原名、新名与命名冲突，可处理全部照片或仅选中照片。
- **保留文件关系**：按关联处理 JPG、RAW 与 XMP；保存常用方案，执行记录支持在文件未变化时恢复原名。

例如：把 `DSC_1234.jpg` 这类相机文件名，整理成 `2026-10-31_旅行_001.jpg`，日期、文字和编号自由组合，先预览再统一执行。

改名前需先保存照片信息。外置磁盘支持 ExFAT 兼容改名；目录授权、额外空间等限制见[详细说明](docs/BEHAVIOR.md)。

## 修改如何保存

**先预览，确认后再写入。** 浏览、编辑和应用预设不会立即改动原文件；保存前可撤销。

默认点击“写入所有元数据”（⌘S），一起保存定位与字段修改；也可在设置中改为仅保存当前页。保存范围不受列表选择或筛选限制。本地文件按备份设置处理并回读核对，保存失败保留待处理修改，不重新压缩照片像素。

苹果“照片”图库通过系统接口更新，仅支持定位与日期，功能与备份范围不同于本地文件。JPG＋RAW 配对可同步定位，其他元数据字段不会自动复制。

## 从一批照片开始

1. **导入照片**：打开或拖入文件，核对拍摄时间与相机时区。
2. **补上地点**：按侧栏步骤选择照片并补齐定位，或直接在地图上选点。
3. **完善信息**：填写常用字段，或用预设批量处理。
4. **保存修改**：核对后写入文件；需要时再预览并执行重命名。

每一步都可单独使用。从列表移除照片不会删除原文件；导出照片副本也不会覆盖原片。

## 大量照片与缓存

导入显示进度与预计剩余时间，缩略图按需加载。设置、收藏与轨迹缓存会保留；缩略图和元数据读取缓存会在下次启动时重建。

## 语言

支持简体中文、English、繁體中文、日本語、한국어、Español 和 Português do Brasil，可在设置中切换，保存工作并重开应用后生效。

首次设置时，简体中文默认使用高德地图，其他语言默认使用 Apple 地图，也可自行选择。界面语言不影响照片时间；地图语言由服务商决定。

[下载最新正式版](https://github.com/LittleSixNine/PhotoTrail/releases/latest) · [查看版本记录](https://github.com/LittleSixNine/PhotoTrail/releases)

支持 **macOS 14 及以上**，兼容 Apple 芯片与 Intel Mac。软件免费使用。当前安装包尚未完成 Developer ID 签名与 Apple 公证，首次打开可能被 macOS 拦截。自动下载更新默认关闭，安装需手动完成。



## 高德服务与费用

高德支持中国大陆地图选点与定位转换。使用前需自行申请并在设置中填写 **Web 端 JS API Key 和 securityJsCode**，新用户的凭据默认在本机加密保存，正式版与测试版共用；已有钥匙串记录继续兼容，可在设置中主动改用本地共享。普通偏好仍各自独立。Apple 地图不需要高德密钥。

超出免费额度或使用付费服务时，费用由高德向你的开发者账号收取。PhotoTrail 不收费，也不代收地图服务费用。

## 坐标与隐私

- **照片文件在本地处理**，不会上传给高德。启用高德后，搜索词和地图相关坐标会发送给高德；主动显示未缓存轨迹或刷新转换时，也会发送所需的轨迹坐标。
- **区分地图坐标与照片坐标**：高德确认的位置经校验后转换为 WGS84，目前仅接受行政区校验通过的中国大陆选点。原照片未声明坐标系时只暂按 WGS84 显示，不自动改写。
- **保留原始轨迹**：地图转换不改写源轨迹，时间匹配仍使用原始 WGS84 数据。坐标校验不能保证原始 GPS 或选点本身准确。

## 项目来源

PhotoTrail 从为相机照片和胶片扫描文件补定位开始，逐步扩展到照片信息与文件命名。部分照片处理能力源自 [marchyman/GeoTag](https://github.com/marchyman/GeoTag)。

## Agent Skill

不打开 Mac App，也可以让 agent 整理照片。独立的 [PhotoTrail Skill](skill/) 支持从照片生成 GPX，或用 GPX 为照片补定位，输出 JPEG／HEIC 副本与报告，保留原片。

### 安装方式

将下面这段话发给具备本地文件访问与命令执行能力的 agent：

> 请阅读 https://raw.githubusercontent.com/LittleSixNine/PhotoTrail/phototrail/skill/INSTALL.md ，按照说明安装 PhotoTrail skill，并检查运行环境。

需要 **Python 3.11+ 和 ExifTool**，目前已在 macOS 验证。Skill 不接入地图搜索或苹果“照片”图库，暂不提供 RAW／XMP 写入。详见[七语言使用指南](docs/i18n/SKILL.zh-Hans.md)和[参数说明](skill/SKILL.md)。

## 开发

需要完整 Xcode（Swift 6.3+、macOS 26 SDK+）、XcodeGen 和 SwiftLint。

```sh
xcodegen generate
xcodebuild -project PhotoTrail.xcodeproj -scheme PhotoTrail \
  -configuration Debug -destination 'platform=macOS' build
```

构建、测试与配置见[开发说明](docs/DEVELOPMENT.md)，功能边界见[功能与数据约定](docs/BEHAVIOR.md)。
